Send a password securely with a one-time link

Put only the password in a NO SUS (nosus.foo) note and send the one-time link. Send the username in another message. The note opens once, then it is deleted. Free, no account, encrypted in your browser. If the password was reused elsewhere, change it afterwards.

Try it · Encrypted in your browser

0/50,000

While a 6-digit code you ask for is valid (10 min), and up to 10 min after, the key is also held on our server.

How it works in four steps

  1. 1

    Step 1: Paste only the password

    Type or paste it in the Note tab above; leave the username and the site's name out of the note.

  2. 2

    Step 2: Create the link

    Tap Create a share link. The key stays in the link, after the #.

  3. 3

    Step 3: Send it where only they look

    Tap Share and pick their chat. No link possible? Under More, Use a code instead gives a 6-digit code to read out on a call.

  4. 4

    Step 4: Confirm, then change it

    Ask them to confirm they saw it; if the password is reused anywhere, or was already pasted in a chat, change it.

Honest limits

  • Whoever opens the link first sees the password. If they find it already used, change the password.
  • If you ask for a 6-digit code, the key is also held on our server until up to 10 minutes after the code is used or expires, so use it soon.
  • The recipient can copy or screenshot the password once it is on their screen.
  • A password already sent in a chat stays in that chat's history; a new link does not remove it, so change that password.

Questions

How do I send a password securely online for free?

Paste it into a one-time note at nosus.foo, send the link where only they will see it, and send the username apart. It is free and neither of you needs an account.

Is it safe to send a password in a one-time link?

Safer than pasting it in a chat, but not perfect. The link stops working after one open and the note is deleted, but the recipient can copy it, and if you ask for a 6-digit code, the key sits on our server until up to 10 minutes after it is used or expires.

Can I send it without a link?

Yes. Under More, tap Use a code instead and read the 6-digit code out on a call; they type it at nosus.foo/#redeem. It opens once within 10 minutes, and our server holds the key until up to 10 minutes after it is used or expires.

I already sent a password on WhatsApp. What now?

Change that password. The message stays in both chat histories and in any backups, and a one-time link sent afterwards does not remove it.

Should I send the username with the password?

Send the username separately, by normal chat. The one-time note then holds only the password, which is the part worth protecting.

How is this different from Bitwarden Send?

Bitwarden's page says its text Sends hold up to 1,000 encrypted characters, and file Sends need a premium account. NO SUS takes up to 50,000 characters and needs no account. If you already use Bitwarden, its Send is a fine choice.
