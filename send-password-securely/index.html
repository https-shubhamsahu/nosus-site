Send a password securely with a one-time link

Put the password in a NO SUS (nosus.foo) note and send the one-time link in one app. Tell the person the 2-digit code in another, such as a call. The note opens once, then it is deleted. Free, no account, encrypted in your browser. If the password was reused elsewhere, change it afterwards.

Try it · Encrypted in your browser

0/50,000

While its 2-digit code (20 min) or a 6-digit code you ask for (10 min) is valid, the key is also held on our server.

How it works in four steps

  1. 1

    Step 1: Paste only the password

    Type or paste it in the Note tab above; leave the username and the site's name out of the note.

  2. 2

    Step 2: Create the link

    Tap Create a share link and wait for the 2-digit code to appear.

  3. 3

    Step 3: Use two channels

    Send the link in one app, such as email, and say the 2-digit code in another, such as a phone call.

  4. 4

    Step 4: Confirm, then change it

    Ask them to confirm they saw it; if the password is reused anywhere, or was already pasted in a chat, change it.

Honest limits

  • The code is only 2 digits and works together with an unguessable link, so it is a second check, not a strong password.
  • While a code is valid (2 digits: 20 minutes by default; the optional 6-digit code: 10 minutes) the key is also held on our server, so use them soon after you send them.
  • The recipient can copy or screenshot the password once it is on their screen.
  • A password already sent in a chat stays in that chat's history; a new link does not remove it, so change that password.

Questions

How do I send a password securely online for free?

Paste it into a one-time note at nosus.foo, send the link, and give the 2-digit code over a different channel. It is free and neither of you needs an account.

Is it safe to send a password in a one-time link?

Safer than pasting it in a chat, but not perfect. The link stops working after one open and the note is deleted, but the recipient can copy it, and the key sits on our server while the 2-digit code is valid (20 minutes by default).

Should I send the link and the code in the same message?

No. If both travel together, anyone who sees that message has everything. Send the link by email or chat and say the code on a call or in a different app.

I already sent a password on WhatsApp. What now?

Change that password. The message stays in both chat histories and in any backups, and a one-time link sent afterwards does not remove it.

Should I send the username with the password?

Send the username separately, by normal chat. The one-time note then holds only the password, which is the part worth protecting.

How is this different from Bitwarden Send?

Bitwarden's page says its text Sends hold up to 1,000 encrypted characters, and file Sends need a premium account. NO SUS takes up to 50,000 characters and needs no account. If you already use Bitwarden, its Send is a fine choice.
