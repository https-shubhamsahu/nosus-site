FAQ

Straight answers.

Including the uncomfortable ones.

Read the product guide

Do I need an account to try a burn note?

No. Burn Notes and Burn Files work without an account for both the sender and recipient. You can create a burn note directly on nosus.foo, then share its one-time link.

How do Burn Notes and Burn Files work?

They are encrypted in your browser with AES-256 before upload, and the direct link keeps the key in the URL fragment. Each opens once, then the server deletes it. Each single note or file also gets a two-digit pairing code; while that code is valid (20 minutes by default) its key is held on our server too, and it is swept within about 10 minutes after the code is used or expires. Notes hold up to 50,000 characters; Burn Files take up to 10 files, 50 MB combined, as one link.

What happens on a borrowed computer?

Open nosus.foo/go on that computer, scan its QR code with your phone, match the code it shows, and approve with your phone's screen lock. The computer never gets your Google password or token. It shows only items you approve, for at most 60 minutes. Downloads and prints may stay on that computer, so only approve a code on a screen in front of you.

Can I prevent screenshots?

In the Android app, yes: screenshots and screen recording of protected documents are blocked. A browser can't block screenshots, so on the web NO SUS deters and traces instead, with touch-to-reveal blur and watermarks tied to the viewer. Nothing can stop someone photographing a screen.

What happens if your servers get hacked?

For Burn Notes and Burn Files, an attacker who breaks in while a drop's two-digit pairing code is still valid (20 minutes by default) could find its key, whichever link you shared. Once the code is used or expires and the key is swept, only ciphertext with no key is left. For other stored documents, access-control policies would need to be bypassed too, and since those files aren't end-to-end encrypted, a full breach of the storage layer could expose their contents.

Is there an iPhone app?

Not a native one. The web app at app.nosus.foo works in Safari, and in any browser on a phone or computer.

How do I get the Android app?

NO SUS for Android is in closed testing on Google Play. Join the testers group first, then become a tester on Google Play and install the app from there.
