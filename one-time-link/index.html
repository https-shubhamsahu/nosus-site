Create a one-time link that stops working after one open

A one-time link opens once and then stops working. NO SUS (nosus.foo) makes one free: paste up to 50,000 characters or add up to 10 files, and your browser encrypts them before upload. The first person to open the link uses it up, and the server deletes its copy. Nobody needs an account.

How it works in four steps

  1. 1

    Step 1: Paste or add

    Type or paste text in the Note tab above, or switch to the File tab and add up to 10 files, 50 MB combined.

  2. 2

    Step 2: Generate the link

    Tap Create a share link; everything is encrypted in your browser before it is uploaded.

  3. 3

    Step 3: Send the link

    Tap Share or Copy link and send it in any chat or email. No link possible? Under More, Use a code instead gives a 6-digit code.

  4. 4

    Step 4: First open uses it up

    The first person to tap Open gets the content, and after that the link is dead for everyone.

One-time link for file sharing

Switch to the File tab and add up to 10 files, 50 MB combined. They travel as one link that opens once. Once your recipient saves them, that copy is theirs: the link can't take it back.

More on files, PDFs included: send a file that deletes after it is opened.

One-time link for text

Paste the text in the Note tab. The reader sees it once in their browser, with no app or account, and then the link is dead for everyone. See self-destructing notes.

One-time link for Google Drive or WhatsApp

Neither has one built in. Google's Drive help describes no link that stops after one open or download, and WhatsApp's view once covers only photos, videos and voice messages.

So the file goes into a one-time link and the link goes into the chat or email: Google Drive one-time download link or a view once PDF on WhatsApp.

Honest limits

  • Whoever opens the link first wins, so send it only where your recipient will see it before anyone else does.
  • The recipient can still copy, screenshot or save what they open; a one-time link cannot take that back.
  • If you ask for a 6-digit code, the key is also held on our server until up to 10 minutes after the code is used or expires.
  • You cannot reopen a link yourself: if you open it to check, you have used it up.

Questions

How does a one-time link work?

The encrypted content is stored under a random ID. The key sits in the link after the #, which browsers do not send to a server. A 6-digit code needs no link at all and opens once; while it is valid, and for up to 10 minutes after, our server holds the key. Either way the content is fetched once and deleted, so nothing is left to open a second time.

What happens if someone else opens my one-time link first?

They get the content and your recipient finds the link dead. That is why a one-time link is also a warning: if your recipient says it is already used, assume someone else saw it. Send the content again with a new link.

Does a chat app's link preview use up the link?

No. A note is fetched and deleted only when the reader taps Open note, so a preview in a chat app does not use it up.

How long does a one-time link last if nobody opens it?

An unread note expires after 7 days. For files you choose 1 hour, 24 hours or 7 days. A 6-digit code opens once and lasts up to 10 minutes.

Is there a one time url generator that needs no account?

Yes. nosus.foo makes one-time links in any browser, and neither you nor the person opening it needs an account. Your browser encrypts the content first, and the key stays in the link after the #, which browsers do not send to a server.

Is there an open-source one-time link tool I can host myself?

Yopass is one. Its README says the browser encrypts the secret before it reaches the server, that links can be one-time, and that it needs no user account. You run it yourself; NO SUS is hosted for you and is not open source.
