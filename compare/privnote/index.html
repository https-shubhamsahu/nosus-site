Privnote alternative: NO SUS vs Privnote

Privnote and NO SUS (nosus.foo) both encrypt a note in your browser, need no account, and delete it after one read. Privnote has run since 2008 and adds timed notes, custom passwords and read alerts by email. NO SUS adds files (up to 10, 50 MB) and shows no ads, but briefly holds each note's key on its server.

How it works in four steps

  1. 1

    Step 1: Type the address yourself

    Whichever tool you use, type privnote.com or nosus.foo into the address bar instead of clicking a search result or ad.

  2. 2

    Step 2: Write the note

    On NO SUS, use the Note tab above; for files, switch to the File tab.

  3. 3

    Step 3: Send link and code apart

    Send the link in one app and the 2-digit code in another, or by voice.

  4. 4

    Step 4: It opens once

    After the reader taps Open note, the link stops working and the note is deleted from the server.

Honest limits

  • Privnote has a much longer track record: it launched in 2008, and NO SUS is new.
  • Privnote's privacy policy says the key never reaches its servers; NO SUS also holds a note's key on its server while its 2-digit code (20 minutes by default) or a 6-digit code you ask for (10 minutes) is valid.
  • Privnote offers timed notes several people can read, custom passwords and an email when the note is read; NO SUS notes have none of these.
  • NO SUS is not open source and Privnote's site links to no source code, so with both you trust the code the site serves.

Questions

Is Privnote safe?

Privnote's privacy policy says notes are encrypted in your browser and the key lives only in the link, so Privnote can't read them. The bigger risk is fake lookalike sites, so type privnote.com yourself instead of clicking a search result or ad.

How do I avoid fake Privnote sites?

Type privnote.com carefully or use a bookmark. In 2024 KrebsOnSecurity reported lookalike sites that ranked in search results and quietly swapped cryptocurrency addresses in notes for the scammers' own.

Can Privnote or NO SUS stop screenshots?

No. Privnote's FAQ says it can't stop the reader copying or capturing a note, and a browser can't block screenshots on NO SUS either. Both only make the link work once.

Can I send files with Privnote?

Privnote's note page takes text only. NO SUS Burn Files sends up to 10 files, 50 MB combined, as one link that opens once.

Which keeps an unread note longer?

Privnote deletes unread notes after 30 days. An unread NO SUS note expires after 7 days.

Is NO SUS free like Privnote?

Both are free to use. Privnote shows third-party ads; NO SUS shows none.
