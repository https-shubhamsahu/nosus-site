WhatsApp पर PDF को view once की तरह कैसे भेजें

नहीं भेज सकते: WhatsApp का view once सिर्फ़ photo, video और voice message के लिए है। इसके बजाय यहाँ Burn File बनाएँ, जो आपके browser में encrypt होती है, और उसका link chat में paste करें। वो एक बार खुलती है, फिर हमारा server उसे delete कर देता है। खोलने वाला file save या उसकी photo ले सकता है।

File चुनें · आपके browser में encrypt होती है

0/50,000

माँगा गया 6-digit code (10 मिनट) valid रहने तक, और उसके बाद 10 मिनट तक, key हमारे server पर भी रखी रहती है।

कैसे काम करता है पाँच steps में

  1. 1

    Step 1: PDF चुनें

    ऊपर tool में File दबाएँ और अपनी PDF चुनें। एक link में 10 files तक, कुल 50 MB, आ सकती हैं।

  2. 2

    Step 2: Expiry चुनें

    अगर किसी ने नहीं खोली, तो link 1 घंटे, 24 घंटे या 7 दिन बाद expire हो जाता है।

  3. 3

    Step 3: Link बनाएँ

    Upload से पहले आपका browser file को AES-256 से encrypt करता है और आपको एक बार चलने वाला link देता है।

  4. 4

    Step 4: WhatsApp में paste करें

    पूरा link भेजें: key # के बाद वाले हिस्से में रहती है।

  5. 5

    Step 5: वो एक बार खुलती है

    पहली बार खुलने के बाद server file delete कर देता है, और link काम करना बंद कर देता है।

ईमानदार सीमाएँ

  • जो भी खोलेगा, वो PDF save, forward या screenshot कर सकता है: एक बार का मतलब link है, उसकी कॉपी नहीं।
  • जिसके पास पूरा link है, वो उसे सबसे पहले खोल सकता है, इसलिए link सिर्फ़ उसी को भेजें जिसे आप भेजना चाहते हैं।
  • WhatsApp के अंदर view once photo की तरह, browser screenshot को रोक नहीं सकता।

सवाल

क्या WhatsApp पर PDF को view once की तरह भेज सकते हैं?

नहीं। View once photo, video और voice message के लिए है। PDF एक normal document की तरह जाती है और chat में रहती है।

क्या पाने वाले को app या account चाहिए?

नहीं। वो link दबाते हैं और file उनके browser में खुल जाती है। न आपको account चाहिए, न उन्हें।

क्या वो screenshot ले सकते हैं या file save कर सकते हैं?

हाँ। खोलने के बाद वो file save कर सकते हैं या screen की photo ले सकते हैं। एक बार का मतलब है कि link काम करना बंद कर देता है, ये नहीं कि उनकी कॉपी गायब हो जाती है।

6-digit code क्या है?

बिना link के भेजने का तरीका। More में Use a code instead दबाएँ, तो 6-digit code मिलता है, जो एक या कई files खोलता है। उसके valid रहने तक, ज़्यादा से ज़्यादा 10 मिनट, key हमारे server पर भी रहती है, फिर इस्तेमाल होने या expire होने के 10 मिनट के अंदर हटा दी जाती है।

क्या WhatsApp view once का screenshot लिया जा सकता है?

WhatsApp कहता है कि वो view once photo और video के screenshot रोकता है। लेकिन दूसरा phone screen की photo ले ले, तो वो नहीं रोक सकता। PDF तो view once media ही नहीं है, इसलिए उसके screenshot को कुछ नहीं रोकता।

न खुले तो view once message कितने दिन रहता है?

WhatsApp न खुला view once message 14 दिन रखता है। NO SUS Burn File का link आपकी चुनी हुई अवधि के बाद, यानी 1 घंटे, 24 घंटे या 7 दिन में expire हो जाता है।
