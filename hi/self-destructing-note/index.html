खुद मिटने वाला note भेजें, जो सिर्फ़ एक बार खुलता है

NO SUS (nosus.foo) आपके browser में खुद मिटने वाला note बनाता है: 50,000 characters तक लिखें और link share करें। Note upload से पहले AES-256 से encrypt होता है, एक बार खुलता है, और फिर server से delete हो जाता है। न पढ़ा गया note 7 दिन बाद expire हो जाता है। न आपको account चाहिए, न पढ़ने वाले को।

आज़माएँ · आपके browser में encrypt होता है

0/50,000

कैसे काम करता है चार steps में

  1. 1

    Step 1: Note लिखें

    ऊपर Note tab खोलें और 50,000 characters तक type या paste करें।

  2. 2

    Step 2: Link बनाएँ

    Create a share link दबाएँ; कुछ भी upload होने से पहले note आपके browser में encrypt हो जाता है।

  3. 3

    Step 3: Link भेजें

    Share दबाकर chat चुनें, या Copy link करें। Key link के # के बाद वाले हिस्से में रहती है।

  4. 4

    Step 4: वो एक बार पढ़ते हैं

    पढ़ने वाला Open note दबाता है, और उसके बाद वो link किसी के लिए नहीं चलता।

ईमानदार सीमाएँ

  • पढ़ने वाला फिर भी note copy, screenshot या उसकी photo ले सकता है; browser इसे रोक नहीं सकता।
  • अगर आप 6-digit code माँगें, तो code इस्तेमाल होने या expire होने के ज़्यादा से ज़्यादा 10 मिनट बाद तक उसकी key हमारे server पर भी रहती है।
  • जो link सबसे पहले खोलता है, वही उसे इस्तेमाल कर लेता है, इसलिए link वहीं भेजें जहाँ आपका पढ़ने वाला उसे देखेगा।
  • Website पर बने notes में custom timer नहीं है: न पढ़ा गया note 7 दिन बाद expire हो जाता है।

सवाल

क्या खुद मिटने वाले note का screenshot लिया जा सकता है?

हाँ। Note पढ़ने वाले की screen पर आते ही वो उसे copy, screenshot या उसकी photo ले सकता है। खुद मिटने का मतलब है कि link एक ही बार चलता है और stored copy delete हो जाती है। ये नहीं कि पढ़ने वाला जो देख चुका, उसे रख नहीं सकता।

खुद मिटने वाला note कितनी देर तक रहता है?

एक बार खुलने तक। न पढ़ा गया NO SUS note 7 दिन में expire हो जाता है। 6-digit code एक बार खुलता है और ज़्यादा से ज़्यादा 10 मिनट चलता है।

क्या NO SUS मेरा note पढ़ सकता है?

Note upload से पहले आपके browser में encrypt होता है, और key link के # के बाद रहती है, जिसे browser नहीं भेजता। सिर्फ़ 6-digit code माँगने पर key हमारे server पर रहती है, code इस्तेमाल होने या expire होने के ज़्यादा से ज़्यादा 10 मिनट बाद तक, इसलिए उस दौरान server में सेंध लगे तो note खुल सकता है।

क्या खुद मिटने वाला email भेज सकते हैं?

Email के रूप में नहीं। Note बनाएँ, फिर उसका link किसी भी email या chat में paste करें। Note एक बार खुलता है और delete हो जाता है, पर email खुद दोनों inbox में रहता है। Link preview या mail scanner उसे इस्तेमाल नहीं करता: note तभी लाया जाता है जब पढ़ने वाला Open note दबाता है।

खुद मिटने वाला message भेजने के लिए क्या app या account चाहिए?

नहीं। ये nosus.foo पर किसी भी browser में चलता है। न भेजने वाले को account या app चाहिए, न पढ़ने वाले को, और ये free है।

क्या Privnote का ऐसा alternative है जो files भी भेजे?

हाँ। Privnote 2008 से चल रहा है और text भेजता है। NO SUS text और 10 files तक, कुल 50 MB, भेजता है। Privnote में कुछ features भी हैं जो NO SUS में नहीं हैं, जैसे custom password।
