ऐसा one-time link बनाएँ जो एक बार खुलने के बाद बंद हो जाए

One-time link एक बार खुलता है और फिर चलना बंद कर देता है। NO SUS (nosus.foo) पर ये free बनता है: 50,000 characters तक text या 10 files तक जोड़ें, और browser उन्हें upload से पहले encrypt करता है। पहली बार खोलने वाला link इस्तेमाल कर लेता है, और server अपनी copy delete कर देता है। Account नहीं चाहिए।

आज़माएँ · आपके browser में encrypt होता है

0/50,000

कैसे काम करता है चार steps में

  1. 1

    Step 1: Paste करें या जोड़ें

    ऊपर Note tab में text type या paste करें, या File tab पर जाकर 10 files तक जोड़ें, कुल 50 MB तक।

  2. 2

    Step 2: Link बनाएँ

    Create a share link दबाएँ; upload होने से पहले सब कुछ आपके browser में encrypt हो जाता है।

  3. 3

    Step 3: Link भेजें

    Share या Copy link दबाकर उसे किसी भी chat या email में भेजें। Link नहीं भेज सकते? More में Use a code instead से 6-digit code लें।

  4. 4

    Step 4: पहली बार खुलते ही खत्म

    जो सबसे पहले Open दबाता है, उसे content मिलता है, और उसके बाद वो link सबके लिए बेकार हो जाता है।

ईमानदार सीमाएँ

  • जो link सबसे पहले खोलता है, वही जीतता है, इसलिए link वहीं भेजें जहाँ आपका पढ़ने वाला उसे किसी और से पहले देखेगा।
  • पढ़ने वाला जो खोलता है, उसे फिर भी copy, screenshot या save कर सकता है; one-time link ये वापस नहीं ले सकता।
  • अगर आप 6-digit code माँगें, तो code इस्तेमाल होने या expire होने के ज़्यादा से ज़्यादा 10 मिनट बाद तक key हमारे server पर भी रहती है।
  • आप अपना link दोबारा नहीं खोल सकते: अगर आपने चेक करने के लिए खोल लिया, तो वो इस्तेमाल हो चुका।

सवाल

One-time link कैसे काम करता है?

Encrypted content एक random ID के नीचे store होता है। Key link के # के बाद वाले हिस्से में रहती है, जिसे browser server को नहीं भेजता। 6-digit code को link की ज़रूरत ही नहीं और वो एक बार खुलता है; उसके valid रहने तक, और उसके बाद ज़्यादा से ज़्यादा 10 मिनट, key हमारे server पर रहती है। दोनों तरह से content एक बार लाया जाता है और delete हो जाता है, इसलिए दूसरी बार खोलने को कुछ बचता नहीं।

अगर मेरा one-time link कोई और पहले खोल ले तो क्या होगा?

उसे content मिल जाएगा और आपके पढ़ने वाले को link बंद मिलेगा। इसीलिए one-time link एक चेतावनी भी है: अगर पढ़ने वाला कहे कि link पहले ही इस्तेमाल हो चुका है, तो मान लें कि किसी और ने देख लिया। Content नए link के साथ दोबारा भेजें।

क्या chat app का link preview link को इस्तेमाल कर देता है?

नहीं। Note तभी लाया और delete किया जाता है जब पढ़ने वाला Open note दबाता है, इसलिए chat app का preview उसे खत्म नहीं करता।

अगर कोई न खोले तो one-time link कितने दिन चलता है?

न पढ़ा गया note 7 दिन बाद expire हो जाता है। Files के लिए आप 1 घंटा, 24 घंटे या 7 दिन चुनते हैं। 6-digit code एक बार खुलता है और 10 मिनट तक चलता है।

क्या password के लिए one-time link बना सकते हैं?

हाँ, और ये chat में password सीधे paste करने से बेहतर है। Link ऐसी जगह भेजें जहाँ सिर्फ़ वो देखें, या call पर 6-digit code बोलकर बताएँ। पूरा तरीका password सुरक्षित भेजने वाले page पर है।

क्या कोई open-source one-time link tool है जिसे मैं खुद host कर सकूँ?

Yopass ऐसा ही एक tool है। उसकी README कहती है कि secret server तक पहुँचने से पहले browser में encrypt होता है, links one-time हो सकते हैं, और user account नहीं चाहिए। उसे आपको खुद चलाना पड़ता है; NO SUS आपके लिए host किया हुआ है और open source नहीं है।
