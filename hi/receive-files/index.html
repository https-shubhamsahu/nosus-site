Read in English

ऐसे इंसान से file पाएँ जिसके पास app नहीं है

भेजने वाले से कहें कि nosus.foo खोलकर File tab से 10 files तक जोड़े, कुल 50 MB। Files उसके browser में encrypt होती हैं, और वो आपको link email या chat से भेज देता है। न आपको account चाहिए, न उसे, और link एक बार खुलता है। NO SUS में अजनबियों के लिए upload page नहीं है।

File चुनें · आपके browser में encrypt होती है

0/50,000

कैसे काम करता है चार steps में

  1. 1

    Step 1: उन्हें nosus.foo पर भेजें

    भेजने वाले से कहें कि phone या computer के किसी भी browser में nosus.foo खोले।

  2. 2

    Step 2: वो files जोड़ते हैं

    वो Burn tool में File दबाकर 10 files तक जोड़ते हैं, कुल 50 MB।

  3. 3

    Step 3: वो आपको link भेजते हैं

    वो एक बार चलने वाला link copy करके आपको उसी रास्ते से भेजते हैं जिससे वो आप तक पहुँचते हैं, जैसे email।

  4. 4

    Step 4: एक बार खोलें

    आप link खोलते हैं, जो चाहिए वो save कर लेते हैं, और files हमारे server से delete हो जाती हैं।

ईमानदार सीमाएँ

  • Link पहुँचाने के लिए भेजने वाले को फिर भी आप तक किसी तरह पहुँचना होगा, जैसे email से।
  • हर link एक बार खुलता है, इसलिए खोलते ही ज़रूरी files save कर लें।
  • अगर वो 6-digit code माँगें, तो code इस्तेमाल होने या expire होने के ज़्यादा से ज़्यादा 10 मिनट बाद तक उसकी key हमारे server पर भी रहती है।
  • ये कोई नहीं जाँचता कि भेजने वाला सच में कौन है।

सवाल

क्या Google Drive में file request link होता है?

सीधे तौर पर नहीं। Google का सबसे नज़दीकी तरीका file upload question वाला Google Form है, और हर भेजने वाले को Google account में sign in करना पड़ता है।

क्या कोई बिना account या login के मुझे file भेज सकता है?

हाँ। वो किसी भी browser में nosus.foo पर एक बार चलने वाला link बनाता है, न account चाहिए, न app। उसे खोलने के लिए आपको भी account नहीं चाहिए।

अगर file 50 MB से बड़ी हो तो?

NO SUS Burn कुल 50 MB लेता है। Dropbox के मुताबिक उसके file requests Basic, Plus और Family plans पर 2 GB तक और business plans पर 250 GB तक की files लेते हैं। भेजने वालों को Dropbox account नहीं चाहिए, पर आपको चाहिए।

क्या लोग मेरे NO SUS domain पर files upload कर सकते हैं?

नहीं। आपका domain, आपके phone पर approve करने के बाद, किसी दूसरी screen पर आपकी अपनी NO SUS Chat खोलता है। वो दूसरे लोगों से uploads नहीं लेता।

क्या मैं इससे कई clients से documents collect कर सकता हूँ?

हर भेजने वाले से एक बार में सिर्फ़ एक link। अगर आपको ऐसा एक link चाहिए जिस पर कई लोग upload करें, तो Google Form या Dropbox file request ज़्यादा ठीक है।

मेरे खोलने के बाद file का क्या होता है?

एक बार खुलने के बाद वो हमारे server से delete हो जाती है, या अगर कोई न खोले तो link expire होने पर।
