Xerox shop पर Gmail या WhatsApp login किए बिना print करें

Shop के computer पर अपना NO SUS domain खोलें, जैसे riya.nosus.foo। वो जो QR दिखाए उसे phone से scan करें, number मिलाएँ और approve करें। आपकी NO SUS Chat वहाँ खुल जाती है, और file print के लिए तैयार है। न वहाँ Gmail का password डालना पड़ता है, न file shop के WhatsApp पर भेजनी पड़ती है।

कैसे काम करता है पाँच steps में

  1. 1

    Step 1: File अपनी chat में रखें

    जाने से पहले, अपने phone पर NO SUS Chat में file जोड़ लें। वो आपके अपने Google Drive में रहती है।

  2. 2

    Step 2: अपना domain खोलें

    Counter पर कहें कि shop के computer के browser में आपका domain खोल दें। वो एक QR code दिखाएगा।

  3. 3

    Step 3: Scan करें और number मिलाएँ

    NO SUS app से QR scan करें, फिर shop की screen पर दिखे number से मेल खाने वाले number पर tap करें।

  4. 4

    Step 4: Approve करें

    अपने phone के screen lock से approve करें। आपकी chat shop के computer पर खुल जाएगी; file वहीं खोलें।

  5. 5

    Step 5: Print करें, फिर सफ़ाई

    Print निकालें, computer के Downloads से file delete करें और tab बंद कर दें। वैसे भी session एक घंटे में ख़त्म हो जाता है।

ईमानदार सीमाएँ

  • Downloads और print की हुई copies shop के computer पर रह सकती हैं, इसलिए निकलने से पहले file delete कर दें।
  • आपके phone में NO SUS app चाहिए, और file पहले से आपकी chat में होनी चाहिए।
  • Shop का computer वो सब देखता है जो आप उस पर खोलते हैं, इसलिए सिर्फ़ वही number approve करें जो आपके सामने की screen पर दिखा हो।

सवाल

क्या Xerox shop पर Gmail में login करना safe है?

Risky है। Shared computer आपको signed in रख सकता है या आपका type किया हुआ save कर सकता है। मजबूरी हो तो guest या private window इस्तेमाल करें, और बाद में अपने phone से signed-in devices देखें। NO SUS Chat में वहाँ password type करना ही नहीं पड़ता।

क्या Xerox shop पर Chrome guest mode safe है?

Normal sign-in से ये ज़्यादा safe है। Google के मुताबिक Guest window बंद करने पर आपकी history, cookies और site data delete हो जाते हैं। लेकिन download या print की हुई files computer पर रह सकती हैं, इसलिए जाने से पहले उन्हें delete करें।

क्या shop के computer को मेरा Google password मिल जाता है?

नहीं। Computer को आपका Google password या token कभी नहीं मिलता। आप जिस session को approve करते हैं, उसके लिए वो आपकी chat दिखाता है, ज़्यादा से ज़्यादा एक घंटे तक।

क्या मेरी file shop के computer पर रह जाएगी?

रह सकती है। Session ख़त्म होने के बाद भी downloads और prints उस computer पर रह सकते हैं, इसलिए निकलने से पहले file को Downloads से delete कर दें।

Xerox shop पर अपना Aadhaar safely कैसे print करूँ?

पहले masked e-Aadhaar download करें। UIDAI के मुताबिक इसमें पहले 8 digits छिपे रहते हैं और सिर्फ़ आख़िरी 4 दिखते हैं, और e-Aadhaar उतना ही valid है जितनी physical copy। उस PDF को अपनी NO SUS Chat में रखें और वही print करें।

जाने से पहले मुझे क्या चाहिए, और क्या कुछ install करना पड़ता है?

सिर्फ़ अपने phone में NO SUS app, Google से signed in, और file पहले से आपकी NO SUS Chat में। Chat आपके अपने Drive में रहती है। Shop के computer पर कुछ install नहीं होता; आप बस उसके browser में अपना domain खोलते हैं।
