बिना account और login के file कैसे भेजें

nosus.foo पर बिना login, sign-up या email के file भेजें; पाने वाले को भी कुछ नहीं चाहिए। 10 files तक जोड़ें, कुल 50 MB, और एक link मिलता है जो एक बार खुलता है। Files पहले browser में encrypt होती हैं। ये account-free है, anonymous नहीं: किसी भी site की तरह इसे आपका IP address दिखता है।

File चुनें · आपके browser में encrypt होती है

0/50,000

माँगा गया 6-digit code (10 मिनट) valid रहने तक, और उसके बाद 10 मिनट तक, key हमारे server पर भी रखी रहती है।

कैसे काम करता है चार steps में

  1. 1

    Step 1: nosus.foo खोलें

    Phone या computer पर कोई भी browser इस्तेमाल करें; न कहीं sign in करना है, न कुछ install करना है।

  2. 2

    Step 2: Files जोड़ें

    ऊपर File दबाएँ और 10 files तक जोड़ें, कुल 50 MB।

  3. 3

    Step 3: तय करें कितना रुकेगा

    1 घंटा, 24 घंटे या 7 दिन चुनें; न खुला link उसके बाद delete हो जाता है।

  4. 4

    Step 4: Link भेजें

    Share दबाएँ, या link को WhatsApp, email या किसी भी chat में copy करें। पाने वाला बिना login खोलता है और उसके बाद link नहीं चलता।

ईमानदार सीमाएँ

  • बिना account का मतलब anonymous नहीं है: किसी भी website की तरह server को आपका IP address दिखता है, और उसका salted hash सिर्फ़ uploads को rate-limit करने के लिए रखा जाता है और 24 घंटे बाद हटा दिया जाता है।
  • कोई ये नहीं जाँचता कि link कौन खोल रहा है, इसलिए जिसके पास link पहले पहुँचे, उसे file मिल जाती है।
  • अगर आप 6-digit code माँगें, तो code इस्तेमाल होने या expire होने के ज़्यादा से ज़्यादा 10 मिनट बाद तक key हमारे server पर रहती है।
  • सीमा 10 files और कुल 50 MB है, इसलिए ये documents और photos के लिए ठीक है, बड़े videos या folders के लिए नहीं।

सवाल

क्या बिना account बनाए file भेज सकते हैं?

हाँ। nosus.foo पर आप files जोड़ते हैं और link पाते हैं; न आप register करते हैं, न sign in, और पाने वाला भी नहीं।

क्या बिना login file भेजना anonymous होता है?

पूरी तरह नहीं। हम नाम या email नहीं माँगते और link में भी ये नहीं होता, लेकिन किसी भी website की तरह connect होने पर server को आपका IP address दिखता है। File uploads के लिए उसका salted hash सिर्फ़ abuse रोकने के rate-limit के लिए रखा जाता है और 24 घंटे बाद हटा दिया जाता है।

जिसके पास account नहीं है, उसे file कैसे share करें?

ऊपर वाला link बनाएँ और उसे WhatsApp, email या किसी भी chat से भेजें। वो उसे browser में खोलकर files save कर लेते हैं, न login चाहिए, न app।

क्या WeTransfer पर भेजने के लिए account चाहिए?

WeTransfer के free-plan page के मुताबिक भेजने के लिए एक free account चाहिए, जबकि पाने वाले को कभी sign up या login नहीं करना पड़ता। उसके free plan में कुल 3 GB और लगातार 30 दिनों में 10 transfers तक का है।

Temporary file link कितनी देर चलता है?

एक बार खुलने तक, या आपकी चुनी expiry तक: 1 घंटा, 24 घंटे या 7 दिन। 6-digit code एक बार खुलता है और 10 मिनट तक चलता है।

बिना account के सबसे बड़ी file कितनी भेज सकते हैं?

यहाँ 10 files तक, कुल 50 MB। बड़ी files के लिए ज़्यादा सीमा वाली service बेहतर है, जैसे WeTransfer की 3 GB की free सीमा।
