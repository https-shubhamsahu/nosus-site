One-time link से password सुरक्षित तरीके से भेजें

सिर्फ़ password को NO SUS (nosus.foo) के note में डालें और one-time link भेजें। Username किसी दूसरे message में भेजें। Note एक बार खुलता है, फिर delete हो जाता है। Free है, account नहीं चाहिए, browser में encrypt होता है। Password कहीं और भी चलता था, तो उसे बदल दें।

आज़माएँ · आपके browser में encrypt होता है

कैसे काम करता है चार steps में

  1. 1

    Step 1: सिर्फ़ password डालें

    उसे ऊपर Note tab में type या paste करें; username और site का नाम note में न रखें।

  2. 2

    Step 2: Link बनाएँ

    Create a share link दबाएँ। Key link में ही, # के बाद, रहती है।

  3. 3

    Step 3: वहीं भेजें जहाँ सिर्फ़ वो देखें

    Share दबाकर उनकी chat चुनें। Link नहीं भेज सकते? More में Use a code instead से 6-digit code लें और call पर बोलकर बताएँ।

  4. 4

    Step 4: पक्का करें, फिर बदलें

    उनसे पूछें कि password दिखा या नहीं; अगर वो कहीं और भी इस्तेमाल होता है, या पहले ही किसी chat में paste हो चुका है, तो उसे बदल दें।

ईमानदार सीमाएँ

  • Link जो पहले खोलेगा, password वही देखेगा। अगर उन्हें link पहले से इस्तेमाल हुआ मिले, तो password बदल दें।
  • अगर आप 6-digit code माँगें, तो code इस्तेमाल होने या expire होने के ज़्यादा से ज़्यादा 10 मिनट बाद तक key हमारे server पर भी रहती है, इसलिए उसे जल्दी इस्तेमाल करें।
  • पाने वाले की screen पर password आने के बाद वो उसे copy या screenshot ले सकता है।
  • जो password पहले ही किसी chat में भेजा जा चुका है, वो उस chat की history में रहता है; नया link उसे नहीं हटाता, इसलिए वो password बदल दें।

सवाल

Password online free में सुरक्षित तरीके से कैसे भेजें?

Password को nosus.foo पर one-time note में paste करें, link ऐसी जगह भेजें जहाँ सिर्फ़ वो देखें, और username अलग से भेजें। ये free है और किसी को account नहीं चाहिए।

क्या one-time link में password भेजना safe है?

Chat में paste करने से ज़्यादा safe, पर पूरी तरह नहीं। Link एक बार खुलने के बाद बंद हो जाता है और note delete हो जाता है, लेकिन पाने वाला उसे copy कर सकता है, और अगर आप 6-digit code माँगें, तो code इस्तेमाल होने या expire होने के ज़्यादा से ज़्यादा 10 मिनट बाद तक key हमारे server पर रहती है।

क्या बिना link के भेज सकते हैं?

हाँ। More में Use a code instead दबाएँ और 6-digit code call पर बोलकर बताएँ; वो उसे nosus.foo/#redeem पर type करें। Code 10 मिनट के अंदर एक बार खुलता है, और key हमारे server पर उसके इस्तेमाल होने या expire होने के ज़्यादा से ज़्यादा 10 मिनट बाद तक रहती है।

मैंने password WhatsApp पर भेज दिया। अब क्या करूँ?

वो password बदल दें। Message दोनों की chat history और किसी भी backup में रहता है, और बाद में भेजा गया one-time link उसे नहीं हटाता।

क्या username भी password के साथ भेजना चाहिए?

Username अलग से, normal chat में भेजें। तब one-time note में सिर्फ़ password रहता है, जो बचाने लायक हिस्सा है।

ये Bitwarden Send से कैसे अलग है?

Bitwarden के page के मुताबिक उसके text Sends में 1,000 encrypted characters तक आते हैं, और file Sends के लिए premium account चाहिए। NO SUS में 50,000 characters तक चलते हैं और account नहीं चाहिए। अगर आप पहले से Bitwarden इस्तेमाल करते हैं, तो उसका Send भी अच्छा विकल्प है।
