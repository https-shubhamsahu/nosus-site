ऐसा file link भेजें जो download के बाद delete हो जाए

NO SUS (nosus.foo) Burn Files से 10 files, कुल 50 MB, एक ऐसे link में भेजें जो एक ही बार चलता है; account नहीं चाहिए। Files browser में encrypt (AES-256) होकर upload होती हैं। खुलते ही link बंद, server की copy delete। न खुला link 1 घंटे, 24 घंटे या 7 दिन में expire होता है।

File चुनें · आपके browser में encrypt होती है

0/50,000

कैसे काम करता है चार steps में

  1. 1

    Step 1: Files जोड़ें

    ऊपर File tab खोलें और 10 files तक जोड़ें, कुल 50 MB।

  2. 2

    Step 2: Expiry चुनें

    1 घंटा, 24 घंटे या 7 दिन चुनें; न खुला link उसके बाद delete हो जाता है।

  3. 3

    Step 3: Link बनाएँ और भेजें

    Create a share link दबाएँ, फिर Share। Link नहीं भेज सकते? More में Use a code instead से 6-digit code लें।

  4. 4

    Step 4: वो खोलकर save करें

    पाने वाला link किसी भी browser में खोलकर files save करता है, और उसके बाद link नहीं चलता।

ईमानदार सीमाएँ

  • Save करने के बाद पाने वाले के पास एक normal copy रहती है, जिसे वो रख, forward या print कर सकता है।
  • अगर वो save करने से पहले page बंद कर दे, तो files चली जाती हैं और link दोबारा नहीं खुलेगा।
  • अगर आप 6-digit code माँगें, तो code इस्तेमाल होने या expire होने के ज़्यादा से ज़्यादा 10 मिनट बाद तक key हमारे server पर भी रहती है।
  • कुल 50 MB की सीमा documents और photos के लिए ठीक है, लंबे videos के लिए नहीं।

सवाल

One-time link कितनी देर चलता है?

एक बार खुलने तक, या आपकी चुनी expiry तक: 1 घंटा, 24 घंटे या 7 दिन। 6-digit code एक बार खुलता है और ज़्यादा से ज़्यादा 10 मिनट चलता है।

Firefox Send का अच्छा alternative क्या है?

Mozilla ने Firefox Send जुलाई 2020 में बंद कर दिया था, जब खबरें आईं कि लोग उससे malware भेज रहे थे, और उसी सितंबर में इसके बंद होने का एलान किया। NO SUS Burn Files उसी तरह काम करता है: files आपके browser में encrypt होती हैं, link में key रहती है, और किसी को account नहीं चाहिए। सीमा है 10 files, कुल 50 MB।

सिर्फ़ एक बार खुलने वाली file कैसे भेजें?

nosus.foo पर अपनी files जोड़ें, expiry चुनें और link बनाएँ। वो एक बार खुलता है, फिर server files delete कर देता है। Link सिर्फ़ उसे भेजें जिसे आप भेजना चाहते हैं, क्योंकि जो सबसे पहले खोलेगा, वही उसे इस्तेमाल कर लेगा।

क्या पाने वाला file अपने पास रख सकता है?

हाँ। One-time का मतलब है कि link एक बार खुलता है; जो वो save कर लेता है, उसे रखना, forward करना या print करना उसके हाथ में है।

Download के बाद delete होने वाली file भेजने के लिए क्या account चाहिए?

नहीं। nosus.foo पर न भेजने वाले को account चाहिए, न पाने वाले को।

क्या एक link में कई files भेज सकते हैं?

हाँ, 10 files तक, कुल 50 MB। Use a code instead एक 6-digit code बनाता है जो बिना link के सब files खोल देता है।
