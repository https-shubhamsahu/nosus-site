Privnote alternative: NO SUS बनाम Privnote

Privnote और NO SUS (nosus.foo) note को browser में encrypt करते हैं, account नहीं माँगते और एक बार पढ़ने पर delete करते हैं। Privnote 2008 से है और timed notes, custom password और read email देता है। NO SUS files (10 तक, 50 MB) भेजता है, और ads नहीं दिखाता।

आज़माएँ · आपके browser में encrypt होता है

0/50,000

माँगा गया 6-digit code (10 मिनट) valid रहने तक, और उसके बाद 10 मिनट तक, key हमारे server पर भी रखी रहती है।

कैसे काम करता है चार steps में

  1. 1

    Step 1: Address खुद type करें

    आप जो भी tool चुनें, search result या ad पर click करने के बजाय address bar में privnote.com या nosus.foo खुद type करें।

  2. 2

    Step 2: Note लिखें

    NO SUS पर ऊपर वाला Note tab इस्तेमाल करें; files के लिए File tab पर जाएँ।

  3. 3

    Step 3: Link भेजें

    Share दबाकर chat चुनें, या Copy link करें।

  4. 4

    Step 4: एक बार खुलता है

    पढ़ने वाले के Open note दबाने के बाद link बंद हो जाता है और note server से delete हो जाता है।

ईमानदार सीमाएँ

  • Privnote का track record काफ़ी लंबा है: वो 2008 में शुरू हुआ था, और NO SUS नया है।
  • Privnote की privacy policy कहती है कि key उसके servers तक कभी नहीं पहुँचती; NO SUS का link भी ऐसे ही काम करता है, पर अगर आप 6-digit code माँगें, तो code इस्तेमाल होने या expire होने के ज़्यादा से ज़्यादा 10 मिनट बाद तक key हमारे server पर भी रहती है।
  • Privnote में timed notes (जिन्हें कई लोग पढ़ सकें), custom password और note पढ़े जाने पर email है; NO SUS के notes में इनमें से कुछ नहीं है।
  • NO SUS open source नहीं है और Privnote की site भी किसी source code से link नहीं करती, इसलिए दोनों में आप उसी code पर भरोसा करते हैं जो site आपको देती है।

सवाल

क्या Privnote safe है?

Privnote की privacy policy कहती है कि notes आपके browser में encrypt होते हैं और key सिर्फ़ link में रहती है, इसलिए Privnote उन्हें पढ़ नहीं सकता। बड़ा खतरा नकली lookalike sites का है, इसलिए search result या ad पर click करने के बजाय privnote.com खुद type करें।

नकली Privnote sites से कैसे बचें?

privnote.com ध्यान से type करें या bookmark इस्तेमाल करें। 2024 में KrebsOnSecurity ने बताया कि lookalike sites search results में ऊपर आ रही थीं और notes में लिखे cryptocurrency addresses को scammers के अपने addresses से बदल देती थीं। एक नकली site ने चार दिन में लगभग $18,000 संभाले।

क्या Privnote या NO SUS screenshot रोक सकते हैं?

नहीं। Privnote की FAQ कहती है कि वो पढ़ने वाले को note copy या capture करने से नहीं रोक सकता, और NO SUS पर भी browser screenshot block नहीं कर सकता। दोनों सिर्फ़ इतना करते हैं कि link एक ही बार चले।

क्या Privnote से files भेज सकते हैं?

Privnote का note page सिर्फ़ text लेता है। NO SUS Burn Files 10 files तक, कुल 50 MB, एक ऐसे link में भेजता है जो एक बार खुलता है।

न पढ़ा note किसके पास ज़्यादा देर रहता है?

Privnote न पढ़े notes को 30 दिन बाद delete करता है। न पढ़ा NO SUS note 7 दिन में expire हो जाता है।

क्या ads के बिना free Privnote alternative है?

NO SUS इस्तेमाल करना free है, ads नहीं दिखाता, और files भी भेजता है। Privnote भी free है, पर उसमें third-party ads हैं। Privnote 2008 से चल रहा है और उसमें note के ज़्यादा options हैं, इसलिए वो अब भी एक ठीक विकल्प है।
