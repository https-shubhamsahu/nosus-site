Send a file link that deletes after download

NO SUS (nosus.foo) Burn Files sends up to 10 files, 50 MB combined, as one link that works once, with no accounts needed. Files are encrypted in your browser (AES-256) before upload. Once the recipient opens them, the link stops working and the server deletes its copy. Unopened links expire after 1 hour, 24 hours or 7 days.

Tap File · Encrypted in your browser

0/50,000

While a 6-digit code you ask for is valid (10 min), and up to 10 min after, the key is also held on our server.

How it works in four steps

  1. 1

    Step 1: Add your files

    Open the File tab above and add up to 10 files, 50 MB combined.

  2. 2

    Step 2: Pick the expiry

    Choose 1 hour, 24 hours or 7 days; an unopened link is deleted after that.

  3. 3

    Step 3: Create and send

    Tap Create a share link, then Share. No link possible? Under More, Use a code instead gives a 6-digit code.

  4. 4

    Step 4: They open and save

    The recipient opens the link in any browser, saves the files, and the link stops working.

Honest limits

  • Once saved, the recipient has a normal copy they can keep, forward or print.
  • If they close the page before saving, the files are gone and the link won't open again.
  • If you ask for a 6-digit code, the key is also held on our server until up to 10 minutes after the code is used or expires.
  • The 50 MB combined cap suits documents and photos, not long videos.

Questions

How long does a one-time link last?

Until it is opened once, or until the expiry you picked: 1 hour, 24 hours or 7 days. A 6-digit code opens once and lasts up to 10 minutes.

What is a good Firefox Send alternative?

Mozilla took Firefox Send offline in July 2020, after reports that people were using it to send malware, and announced its end that September. NO SUS Burn Files works in a similar way: files are encrypted in your browser, the link carries the key, and neither side needs an account. The limit is 10 files, 50 MB combined.

How do I send a file that can only be opened once?

Add your files at nosus.foo, pick an expiry and create the link. It opens once, and then the server deletes the files. Send the link only to the person you mean, because whoever opens it first uses it up.

Can the recipient keep the file?

Yes. One-time means the link opens once; whatever they save is theirs to keep, forward or print.

Do I need an account to send a file that deletes after download?

No. On nosus.foo neither the sender nor the recipient needs an account, and it is free to use.

Can I send several files in one link?

Yes, up to 10 files with a combined size of 50 MB. Use a code instead makes one 6-digit code that opens all of them with no link.
