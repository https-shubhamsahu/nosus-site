Yopass alternative: NO SUS vs Yopass

Yopass and NO SUS (nosus.foo) both encrypt in your browser and need no account. Yopass is open source, built to self-host, and has optional passphrases and a command-line client; its public demo is for testing. NO SUS is hosted with nothing to install and sends files up to 50 MB, but is closed source.

Try it · Encrypted in your browser

While a 6-digit code you ask for is valid (10 min), and up to 10 min after, the key is also held on our server.

How it works in four steps

  1. 1

    Step 1: Pick by who runs it

    Want to run your own server and read the code? Use Yopass. Want a hosted link in seconds, with files? Stay here.

  2. 2

    Step 2: Write the note

    On NO SUS, type or paste it in the Note tab above; for files, switch to the File tab.

  3. 3

    Step 3: Share the link

    Tap Share and pick the chat. No link possible? Under More, Use a code instead gives a 6-digit code to read out.

  4. 4

    Step 4: It opens once

    After the reader taps Open note, the link stops working and the server deletes its copy.

Honest limits

  • Yopass keeps the key out of the server, per its site; so does NO SUS's link, but if you ask for a 6-digit code, our server holds the key until up to 10 minutes after the code is used or expires.
  • Yopass is Apache 2.0 open source and its own README tells you to self-host for sensitive data, so most of its safety comes from a server you run; NO SUS is hosted and its code is not public.
  • Yopass supports optional passphrases, longer expiry set by the host and a command-line client; NO SUS has none of these.
  • Neither can stop a reader taking a screenshot or copying the text once it is on their screen.

Questions

Is Yopass safe?

Yopass's site says secrets are encrypted in your browser with OpenPGP and the decryption key never reaches the server. The code is open source, so you can audit it. Its README says the public demo is for testing and sensitive data belongs on a server you run.

Yopass vs NO SUS: which is better?

Pick Yopass if you can run a server and want open code, a passphrase, a CLI and a key that never touches the server. Pick NO SUS if you want a hosted link with nothing to set up, or need to send files up to 50 MB.

Can I use Yopass without hosting it myself?

There is a public demo at share.yopass.se, but the README says to use it for testing and to self-host for sensitive information. The site lists no paid hosted version.

Does Yopass support files?

Yes, files are encrypted in the browser. The default limit is 512 KB per file and a server without a business licence is capped at 1 MB. NO SUS Burn Files sends up to 10 files, 50 MB combined.

How long does a Yopass secret last?

The choices are 1 hour, 1 day or 1 week. Since version 15.1.0 a host can enable custom expiry from 1 minute to 90 days.

Is Yopass free?

Yes, the open source edition is free to self-host. A business licence costs €149 a year and adds branding, bigger uploads, login, audit logs and read receipts. NO SUS is free to use.
