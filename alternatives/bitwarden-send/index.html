Bitwarden Send alternative with no account

Bitwarden Send needs a Bitwarden account to create a link, though recipients need none. Free accounts send text up to 1,000 encrypted characters; files need Premium, at $19.80 a year. NO SUS (nosus.foo) needs no account on either side and sends a note up to 50,000 characters or up to 10 files, free.

How it works in four steps

  1. 1

    Step 1: Skip the sign-up

    Use the Note tab above; there is nothing to install and no login.

  2. 2

    Switch to the File tab to add up to 10 files, 50 MB combined.

  3. 3

    Tap Share and pick the chat. No link possible? Under More, Use a code instead gives a 6-digit code to read out.

  4. 4

    Step 4: It opens once

    After the reader taps Open note, the link stops working and the note is deleted from the server.

Honest limits

  • Bitwarden Send's key lives only in the link and never reaches Bitwarden's server; NO SUS's link works the same way, but if you ask for a 6-digit code, our server holds the key until up to 10 minutes after the code is used or expires.
  • Bitwarden Send takes files up to 500 MB (100 MB on mobile) with Premium; NO SUS stops at 50 MB combined.
  • Bitwarden Send adds passwords, a view limit, hidden sender email, and on paid plans email-verified recipients; NO SUS has none of these.
  • Bitwarden Send is built into a password manager, can be self-hosted and has code on GitHub; NO SUS is new and not open source.

Questions

Do you need a Bitwarden account to use Bitwarden Send?

To create a Send, yes: Bitwarden says Sends are made inside a Bitwarden account with a verified email. The person who opens the link needs no account.

Can I send a file with Bitwarden Send for free?

No. Text Sends are free, but file Sends need Premium or a paid organization plan. NO SUS Burn Files is free for up to 10 files, 50 MB combined.

How long can a Bitwarden Send last?

A Send is deleted after a date you choose, 7 days by default and about a month at most. You can also end access earlier with an expiration date or a view limit.

Is Bitwarden Send end-to-end encrypted?

Yes. Bitwarden says each Send is encrypted on your device with AES-256 and the key goes only in the link fragment, which browsers do not send to the server.

What is the best Bitwarden Send alternative with no login?

NO SUS works with no login for sender or reader, and one link can carry a note or up to 10 files. If you already use Bitwarden, Send is just as good for text and better for large files.
