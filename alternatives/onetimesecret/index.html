Onetime Secret alternative: NO SUS vs Onetime Secret

Onetime Secret and NO SUS (nosus.foo) both make a link that shows a note once, with no account needed. Onetime Secret is open source, self-hostable, has an API and passphrases, and encrypts on its servers. NO SUS encrypts in your browser and sends files up to 50 MB, but is closed source.

Try it · Encrypted in your browser

0/50,000

How it works in four steps

  1. 1

    Step 1: Pick by what you need

    Need open code, a passphrase, an API or a longer expiry? Use Onetime Secret. Need files or browser-side encryption? Stay here.

  2. 2

    Step 2: Write the note

    On NO SUS, type or paste it in the Note tab above; for files, switch to the File tab.

  3. 3

    Step 3: Share the link

    Tap Share and pick the chat. No link possible? Under More, Use a code instead gives a 6-digit code to read out.

  4. 4

    Step 4: It opens once

    After the reader taps Open note, the link stops working and the server deletes its copy.

Honest limits

  • Onetime Secret has run since 2011 and is open source under the MIT licence; NO SUS is new and its code is not public.
  • Onetime Secret's About page says secrets are encrypted on its servers. NO SUS encrypts in your browser and keeps the key in the link, but if you ask for a 6-digit code, our server holds the key until up to 10 minutes after the code is used or expires.
  • Onetime Secret has optional passphrases, a REST API, longer expiry and paid custom domains; NO SUS has none of these.
  • Neither can stop a reader taking a screenshot or copying the text once it is on their screen.

Questions

Is onetimesecret.com safe?

Its docs say secrets are encrypted in transit and at rest and destroyed after one view, and the code is open source on GitHub. The catch is that its About page says encryption happens on its servers, so you are trusting the operator. Its privacy statement says staff may view a secret only for security, maintenance or support, with the owner's consent.

Onetime Secret vs NO SUS: which is better?

Pick Onetime Secret for open code, self-hosting, a passphrase, an API or expiry up to 14 days on the free plan. Pick NO SUS to send files or to have the note encrypted in your browser. Neither suits secrets you would never let a server see.

Do I need an account for Onetime Secret?

No account is needed for basic use. Its About page says anonymous secrets last up to 7 days and 100 KB; a free account raises that to 14 days and 1,000 KB.

Can Onetime Secret send files?

Its site describes text secrets and lists no file sharing. NO SUS Burn Files sends up to 10 files, 50 MB combined, as one link that opens once.

Can I self-host Onetime Secret?

Yes. The code is MIT licensed and the docs cover Docker setup with Redis. NO SUS cannot be self-hosted.

Is Onetime Secret free?

Yes, there is a free plan with API access and one custom domain. Identity Plus is €35 a month and Team Plus €125 a month. NO SUS is free to use.
