PrivateBin alternative: NO SUS vs PrivateBin

PrivateBin is free, open source pastebin software with burn-after-reading and optional passwords, which you run yourself or use on a server someone else runs. NO SUS (nosus.foo) is hosted for you: nothing to install, no account, a one-time note or up to 10 files. PrivateBin keeps the key in the link only.

How it works in four steps

  1. 1

    Step 1: Decide who runs it

    Want to run your own server, or need an API? Use PrivateBin. Want a one-time note with nothing to install? Continue here.

  2. 2

    Step 2: Write the note

    Use the Note tab above; switch to the File tab to send up to 10 files.

  3. 3

    Step 3: Send link and code apart

    Send the link in one app and the 2-digit code in another, or say it by voice. No link possible? Tap Use a code instead for a 6-digit code.

  4. 4

    Step 4: It opens once

    After the reader taps Open note, the link stops working and the note is deleted from the server.

Honest limits

  • PrivateBin's key lives only in the link; NO SUS also holds a note's key on its server while its 2-digit code (20 minutes by default) or a 6-digit code you ask for (10 minutes) is valid.
  • PrivateBin is open source and can be self-hosted, so you can inspect the code and run it; NO SUS is not open source and cannot be self-hosted.
  • A PrivateBin page is only as trustworthy as whoever runs it, because its README warns an operator could serve altered code. The same is true of NO SUS.
  • PrivateBin adds syntax highlighting, Markdown and optional discussions; NO SUS is for one-time notes and files.

Questions

Is PrivateBin safe?

PrivateBin encrypts in your browser and keeps the key in the link, so the server stores only ciphertext. Its README also says you must trust whoever runs the server, because an operator could serve altered code, so pick an instance you trust or host your own.

Does PrivateBin have burn after reading?

Yes. It is an option on each paste, along with expiry times from 5 minutes to a year or never. NO SUS notes always open once.

Is there an official PrivateBin site I can just use?

PrivateBin is software, and its FAQ points to a directory of instances run by other people. If you want to avoid picking a server, a hosted tool like NO SUS needs no choice.

Can I send files with PrivateBin?

Only if the admin turns file upload on, which is off by default. NO SUS Burn Files sends up to 10 files, 50 MB combined, as one link that opens once.

What is the best PrivateBin alternative with no setup?

For one-time notes, NO SUS needs no install or account. For a pastebin you control, with code highlighting and an API, PrivateBin is the better fit.
