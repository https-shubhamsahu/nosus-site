Password Pusher alternative: NO SUS vs pwpush

Password Pusher (pwpush.com) is the better pick if you need view limits, a passphrase, an audit log, an API or self-hosting. NO SUS (nosus.foo) is simpler: no account, a one-time note or up to 10 files (50 MB combined), encrypted in your browser. Password Pusher encrypts on its server, not in your browser.

Try it · Encrypted in your browser

0/50,000

How it works in four steps

  1. 1

    Step 1: Pick by the job

    Need an audit log, API or your own server? Use Password Pusher. Want a quick one-time note or files with nothing to set up? Continue here.

  2. 2

    Step 2: Write the note

    Use the Note tab above; switch to the File tab to send up to 10 files.

  3. 3

    Step 3: Share the link

    Tap Share and pick the chat. No link possible? Under More, Use a code instead gives a 6-digit code to read out.

  4. 4

    Step 4: It opens once

    After the reader taps Open note, the link stops working and the note is deleted from the server.

Honest limits

  • Password Pusher has been in production for 15+ years, per its README, and is open source (Apache 2.0); NO SUS is new and not open source.
  • Password Pusher's security page says it has no client-side encryption; NO SUS encrypts in your browser and keeps the key in the link, but if you ask for a 6-digit code, our server holds the key until up to 10 minutes after the code is used or expires.
  • NO SUS has no passphrase, audit log, API or view counts above one; its notes simply open once.
  • Password Pusher file uploads need a paid plan (Solo, $19 a month) but have no small cap; NO SUS files are free and capped at 10 files, 50 MB combined.

Questions

Is Password Pusher free?

Yes for basic pushes: its pricing page lists a free plan with no account needed, view and time limits, passphrase links, audit logs and a JSON API. File uploads, custom branding and team features need a paid plan from $19 a month.

Does Password Pusher encrypt in the browser?

No. Its security page says the server encrypts data in its database with AES-256-GCM and that it does not offer client-side encryption. NO SUS encrypts in your browser and holds the key only if you ask for a 6-digit code, until up to 10 minutes after it is used or expires.

Can I send files with Password Pusher for free?

Not on pwpush.com: file uploads start on the Solo plan at $19 a month. NO SUS Burn Files is free for up to 10 files, 50 MB combined.

Can I self-host Password Pusher?

Yes. It is open source under Apache 2.0 and runs with Docker or Kubernetes. A paid Self-Hosted Pro edition also exists. NO SUS cannot be self-hosted.

Which is better for sending a password, NO SUS or Password Pusher?

For a one-off password to one person, NO SUS needs no setup. For a team that wants view limits, an audit trail or an API, Password Pusher fits better. Either way, send the link and any passphrase over different channels.

Is there a Password Pusher alternative with no account?

Password Pusher itself needs no account for basic pushes. NO SUS also needs none, for sender or reader, and adds a one-time file link.
