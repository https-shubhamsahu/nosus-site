Share text online without login. It opens once.

NO SUS (nosus.foo) shares text with no login: paste it, tap Create a share link and send the link. Neither of you signs up. The text is encrypted in your browser, the key stays after the #, which browsers don't send to us, and it's deleted once opened. Phone to laptop? Use a six-digit code.

How it works in four steps

  1. 1

    Step 1: Paste the text

    Type or paste your paragraph, address or code snippet into the Note tab above.

  2. 2

    Step 2: Create the link

    Tap Create a share link; the text is encrypted in your browser before anything is uploaded.

  3. 3

    Step 3: Send link or code

    Tap Share or Copy link, or for your own laptop open More and tap Use a code instead to get six digits.

  4. 4

    Step 4: Open it once

    The reader taps Open note, or types the code under Got a code on nosus.foo, and we delete the text from our server.

Send text from phone to laptop without logging in

On the phone, paste the text, tap Create a share link, then open More and tap Use a code instead. On the laptop, open nosus.foo, pick Got a code and type the six digits. You don't sign in to email or a chat app on that computer.

The code needs no link, opens once and lasts up to 10 minutes. Wrong guesses are limited per network and per install, and a code stops working after 600 wrong guesses across the whole service, so a guesser's chance is at most 600 in a million.

On a cyber cafe or print shop computer, read what to do before you log in there.

Paste text and share a link on WhatsApp or email

Your link opens to a button first. The text is fetched and deleted only when the reader taps Open note, so the preview WhatsApp or an email app makes of the link doesn't use it up.

Sending a password this way? Put the username in a separate message: send a password securely.

Private pastebin or online clipboard: which one you need

If the text should stay up for days or for many readers, you want a pastebin. PrivateBin, for one, lets you set expiry from 5 minutes to a year or never, with burn after reading as an option, and you can run it on your own server.

Pick a note that opens once when the text is for one person, one time: an address, a Wi-Fi password, a snippet you don't want sitting in a chat. That's the job NO SUS does, for text or for files: send files without login.

Share text that expires

A NO SUS note expires when it's read, not on a timer you pick. If you want a short window as well, use the six-digit code: it opens once and runs out after up to 10 minutes.

Honest limits

  • It's for one reading, not a pastebin you come back to: after the first open, the link and the code stop working for everyone, you included.
  • The reader can still copy, screenshot or photograph the text; a browser can't block screenshots.
  • While your six-digit code is valid, our server holds its key; we delete it within 10 minutes after the code is used or expires.
  • Whoever opens the link first uses it up, so send it only where you know your reader will see it.

Questions

Can I share text online without an account?

Yes. On nosus.foo you don't make an account, and neither does the person you send it to. There's nothing to install: you paste the text, make a link and send it.

Can NO SUS read the text I share?

The text is encrypted in your browser before upload, and the key stays in the part of the link after the #, which browsers don't send to us. The one exception is a six-digit code: while it's valid our server holds the key, and we delete it within 10 minutes after the code is used or expires.

Will a WhatsApp or email link preview open the note?

No. Your link first shows a button, and the text is fetched and deleted only when the reader taps Open note, so a preview doesn't use it up.

Can someone guess my six-digit code?

Wrong codes are limited per network and per install, and a code stops working once 600 wrong guesses have been made across the service since it was made. That puts a guesser's chance at most 600 in a million, and the code lasts up to 10 minutes anyway.

Can the person I send it to keep the text?

Yes. Once it's on their screen they can copy it, screenshot it or photograph it. Opening once means the link works one time and the stored copy is deleted, not that the reader forgets what they saw.

Is NO SUS open source like PrivateBin?

No. NO SUS is closed source and you can't host it yourself. PrivateBin, Onetime Secret and Yopass are open source, so pick one of those if you need to read the code or run your own server.
