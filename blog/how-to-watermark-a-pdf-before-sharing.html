The short answer

Write who the copy is for, why, and the date (for example "For KYC at XYZ Bank only, 12 Oct 2026") and run it diagonally across the page so it crosses the photo or key text. Use a tool that runs on your own device (your phone's photo editor or Mac Preview for ID photos, LibreOffice or Word for documents) and send a flattened PDF or image. A watermark labels and deters; it cannot stop cropping, retyping, screenshots or AI removal.

An Aadhaar copy for a SIM card, mark sheets for an admission, a resume for a recruiter, salary slips for a flat. Once a copy leaves your phone, you lose control of where it goes. A watermark makes every copy carry a visible note of what it was meant for, so misuse is easier to spot and harder to explain away. Menu paths below are as of October 2026.

What should a watermark on an ID copy say?

Make the text specific enough that the copy looks wrong anywhere else. Answer three things:

  • Why: "For SIM KYC only", "For rental verification only".
  • For whom: the company, branch or person, e.g. "XYZ Bank, Andheri branch".
  • When: the date you are sharing it. A dated copy is hard to reuse months later without someone noticing.

A full example: For KYC at XYZ Bank only | 12 Oct 2026 | Not valid elsewhere.

Placement matters as much as wording. Run it diagonally and semi-transparent across the page so it crosses the photo and part of the text. Keep the name and number readable, because the person receiving it still has to verify them. A label parked in an empty corner can be cropped off in one tap.

How do you add a watermark in Microsoft Word?

These steps follow Microsoft's watermark help page:

  1. Open the document in the Word desktop app. Word for the web can show a watermark but can't add or change one.
  2. Go to Design > Watermark > Custom Watermark and choose a text watermark. On a Mac, Design > Watermark opens the same dialog; select Text.
  3. Type your text or pick a preset such as DRAFT, then set the font, size, colour and layout. Diagonal is harder to crop out than horizontal.
  4. Click OK. If you can't see it, switch to View > Print Layout.
  5. Save it as a PDF: File > Save a Copy (or Save As), then choose PDF in the format list, per Microsoft's PDF export guide.

Send the PDF, not the .docx. In a Word file the watermark is something any Word user can change. If you paste an ID photo onto the page, open the exported PDF and check that the watermark actually shows over the photo; if the picture hides it, use the Preview or phone method below, which writes the text on top of the image.

How do you watermark a PDF for free with LibreOffice?

LibreOffice is a free, open-source office suite, and everything happens on your computer. Its current help pages describe two ways.

Writer's watermark (more control). From the Page Watermark help page:

  1. Open the document in LibreOffice Writer.
  2. Go to Format > Watermark. In the tabbed interface it is under the Layout tab.
  3. Type your text, then choose the font, angle, transparency and colour. You can't set the font size; Writer scales the text to fit one line across the page.
  4. Export the document as a PDF from the File menu.

The watermark applies to the current page style, so every page using that style gets it.

Watermark during PDF export (quickest). In the PDF export dialog's General tab, tick Sign with watermark and type your text. According to LibreOffice's export help, this adds a centred, vertical, light green watermark whose position, orientation and size you can't change, and it isn't saved in your original file.

Both help pages say the watermark goes on the page background. An opaque photo pasted onto the page will cover it where they overlap, so for ID photos use the Preview or phone method below.

Can you watermark a PDF in Adobe Acrobat for free?

Not with the free tools, going by Adobe's own pages as of October 2026. The Acrobat online tools page lists converting, merging, splitting, compressing, signing and protecting, but no watermark tool. The Acrobat Reader page says text and image editing needs a paid Acrobat plan.

If you already have Acrobat through college or work, Adobe's watermark walkthrough goes like this: open the PDF, then in the edit tools under Add content, choose More > Watermark > Add. Pick text or an image, and set the font, size, opacity, rotation, page range and whether it shows on screen, in print or both. An Apply to multiple files option stamps several PDFs at once.

The same walkthrough covers removing a watermark, and Adobe's online guide covers editing one. That's the catch with every PDF watermark: it is a separate element, not permanent ink.

Does Preview on Mac have a watermark option?

Not a dedicated one. The closest is the Markup Text tool, described in Apple's Preview guide:

  1. Open the PDF in Preview and click Show Markup Toolbar.
  2. Choose the Text tool, type your label and drag it into place. Change the font and colour with the Text Style button.
  3. To lock it in, choose File > Print, then Save as PDF. Apple says this flattens annotations "so that they can't be edited." Plain File > Save or Export keeps them editable.

It works one text box at a time, so it suits short documents.

How do you watermark an ID photo on your phone?

Android, with Google Photos (Google's help page):

  1. Open the photo and tap Edit > Markup. On some phones it's Edit > Tools > Markup.
  2. Tap Text, type your label, then press and hold to drag it into place.
  3. Tap the checkmark, then Save as copy so your original stays untouched.

iPhone, with Photos (Apple's Markup page):

  1. Open the photo, tap Edit, then the Markup button.
  2. Tap the Add (+) button, choose text, type your label and drag it into place.
  3. Tap Done, then Done again.

One short line is easy to crop. Write the label two or three times across the image, including once over the photo. If Google Photos backup is on, your photos, including the edited copy, are saved to your Google Account, per Google's backup help. Check that setting before you photograph IDs.

Is it safe to watermark documents on iLovePDF, Smallpdf or PDF24?

They work, but your file is uploaded to their servers. Their stated policies, as of October 2026:

  • PDF24: free and ad-funded, no sign-up. Files are deleted from its server after one hour. You can set angle and transparency, or fill the whole page with the text.
  • iLovePDF: text or image watermarks with opacity, rotation and page range. Its pricing page limits free-plan batch watermarking to 2 files at a time and keeps the desktop app, which its GDPR page says processes files on your device, for paid plans. Files from the standard web tools are deleted within two hours.
  • Smallpdf: free text watermarks with unspecified usage limits for free users. It says files are deleted one hour after processing.

These are the companies' own statements, not independent audits. For a resume or class notes, that's a fair trade. For Aadhaar, PAN, passport or bank statements, stay offline. Same thinking as not leaving copies behind at the Xerox shop.

Visible vs invisible watermarks: what's the difference?

A visible watermark is text or a logo anyone can see. Its job is context and deterrence.

An invisible watermark is a signal hidden inside the file that needs software to detect. Google DeepMind's SynthID, for example, marks AI-generated content and, for images and video, is designed to survive cropping, filters and compression. The everyday tools above only add visible watermarks.

The practical version for everyone else is a unique copy per recipient. Put each recipient's name in their copy's watermark. If one leaks, the label tells you which copy it was. Variation also helps: a 2017 Google Research paper showed that a watermark applied the same way across many images can be estimated and removed automatically, and looked at inconsistencies in the watermark as a defence.

What can a watermark not stop?

  • Cropping. A watermark in the margin disappears with one crop. Put it across the content.
  • Retyping. Someone can copy your name, number and address by hand. A watermark protects the picture, not the information, so share as little as you can.
  • Editing it out. PDF watermarks can be edited or removed with an editor. Image watermarks can be painted out with AI: in March 2025, TechCrunch reported people using an experimental Gemini 2.0 Flash feature to strip watermarks from stock photos, though it struggled with some semi-transparent marks and ones covering large areas. That was one model, over a year ago, so treat no watermark as removal-proof.
  • Screenshots, photos of the screen and prints. Nothing inside a file prevents these.
  • Proving who leaked it. A label tells you which copy leaked, not who leaked it.
  • Controlling who opens it. A watermark is not a password or encryption. Anyone with the file can read it.

Questions people ask

Can someone remove a watermark from a PDF?

Yes. A watermark added by a PDF tool is usually a separate element, and editors such as Adobe Acrobat can edit or remove it. Flattening the file or sharing it as an image makes removal harder, but not impossible.

What should I write on my Aadhaar or PAN copy before sharing it?

Write the purpose, the recipient and the date, for example "For SIM KYC at XYZ store only, 12 Oct 2026". Place it semi-transparent and diagonally across the photo, while keeping the name and number readable for the person who has to verify them.

Is it safe to watermark ID documents on iLovePDF, Smallpdf or PDF24?

These sites upload your file to their servers. Their own policies say files are deleted within one to two hours, but that is the company's claim. For Aadhaar, PAN or passport copies, use an offline tool like LibreOffice, Word or your phone's photo editor.

Can I add a watermark in Word for the web?

No. Microsoft says Word for the web can display existing watermarks but cannot add or change them. Use the Word desktop app, or LibreOffice Writer, which is free.

Does a watermark stop screenshots or copying?

No. A watermark is a printed label on the document. Anyone who can view the file can screenshot it, photograph the screen or retype the details.
