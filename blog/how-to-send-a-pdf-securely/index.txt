3c:T22d3,<p>To send a PDF securely, protect the file itself and control the link it travels on. Put an open password on the PDF and send that password by a different channel, or share it through a link that expires and can be limited to named people. Gmail confidential mode and Outlook&#39;s Do Not Forward help, but both have gaps, covered below.</p>
<p>None of these stops a recipient from photographing the screen. They reduce who can open the file and how long it lingers. Pick based on what is inside the PDF.</p>
<h2 id="which-way-should-you-send-the-pdf">Which way should you send the PDF?</h2>
<div class="table-scroll" role="region" aria-label="Table" tabindex="0"><table><thead><tr><th scope="col">What you are sending</th><th scope="col">Best option</th><th scope="col">Watch out for</th></tr></thead><tbody><tr><th scope="row">A contract or salary slip to one person</th><td>Password-protected PDF, password sent by another channel</td><td>Weak or reused passwords</td></tr><tr><th scope="row">Something you want to expire or be pulled back</th><td>Drive or OneDrive link set to specific people, or Gmail confidential mode</td><td>Expiry needs a work or school account on Drive</td></tr><tr><th scope="row">A one-off file to someone with no account</th><td>One-time link</td><td>Whoever opens it first gets it</td></tr><tr><th scope="row">Aadhaar for KYC</th><td>Masked Aadhaar, watermark with purpose and date, expiring link</td><td>The copy can still be forwarded</td></tr><tr><th scope="row">A PDF you want to trace if it leaks</th><td>Watermarked link per viewer</td><td>A watermark is a clue, not proof</td></tr></tbody></table></div>
<h2 id="is-gmail-confidential-mode-secure">Is Gmail confidential mode secure?</h2>
<p>It is a useful lock on the door, not a vault. Per <a href="https://support.google.com/mail/answer/7674059" rel="noopener" target="_blank">Google&#39;s help page</a>, confidential mode lets you set an expiry, remove a recipient&#39;s access from your Sent folder, and turn off forwarding, copying, printing and downloading. You can also require an SMS passcode, which works for phone numbers in regions including India.</p>
<p>The limits are written on the same page: recipients can still take screenshots or photos. Google does not describe confidential mode as end-to-end encryption. If the recipient is not on Gmail, they get a <a href="https://knowledge.workspace.google.com/admin/gmail/advanced/protect-gmail-messages-with-confidential-mode" rel="noopener" target="_blank">link instead of the message</a>, so the content sits on Google&#39;s side until they open it.</p>
<p>One number worth knowing: as of 16 October 2026, a personal Gmail account sends and receives up to <a href="https://support.google.com/mail/answer/6584" rel="noopener" target="_blank">25 MB</a>. Bigger attachments become a Drive link automatically, and Drive&#39;s own sharing settings then apply.</p>
<h2 id="how-do-i-send-a-pdf-securely-in-outlook">How do I send a PDF securely in Outlook?</h2>
<p>In a new message, open <strong>Options</strong>, choose <strong>Encrypt</strong>, then pick <strong>Encrypt</strong> or <strong>Do Not Forward</strong>. Microsoft&#39;s <a href="https://support.microsoft.com/en-us/office/learn-about-encrypted-messages-in-outlook-3521aa01-77e3-4cfd-8a13-299eb60b1957" rel="noopener" target="_blank">Outlook encryption page</a> explains the catch for a PDF: under Do Not Forward, PDFs and images can be downloaded without encryption. Word, Excel and PowerPoint files stay encrypted. So for a PDF, Outlook&#39;s setting protects the email more than the file.</p>
<p>Recipients on other providers sign in with a Microsoft, Google or Yahoo account or use a temporary passcode. Add a password on the PDF itself if the content matters.</p>
<h2 id="how-do-i-password-protect-a-pdf-for-free">How do I password-protect a PDF for free?</h2>
<p>Three free routes, all on your device:</p>
<ul>
<li><strong>Word:</strong> Save As PDF, open <strong>Options</strong>, and choose the encrypt-with-a-password option, per <a href="https://support.microsoft.com/en-us/office/save-or-convert-to-pdf-or-xps-in-office-desktop-apps-d85416c5-7d77-4fd6-a216-6f4bf7c7c110" rel="noopener" target="_blank">Microsoft</a>.</li>
<li><strong>Mac Preview:</strong> File, Export, Permissions, then require a password to open it (<a href="https://support.apple.com/guide/preview/password-protect-a-pdf-prvw587dd90f/mac" rel="noopener" target="_blank">Apple</a>).</li>
<li><strong>Adobe Acrobat:</strong> Protect Using Password. Adobe says the &quot;Acrobat X and later&quot; setting uses 256-bit AES and that readers need a version at least that recent (<a href="https://helpx.adobe.com/acrobat/current/securing-pdfs-passwords.html" rel="noopener" target="_blank">Adobe</a>). It also separates an open password from a permissions password, which only restricts printing, editing and copying.</li>
</ul>
<p>Use the open password. A permissions password alone lets anyone read the file.</p>
<h2 id="how-do-i-send-the-password-separately">How do I send the password separately?</h2>
<p>The password has to take a different road from the file. If both sit in one email thread, anyone who reads that thread has both.</p>
<ul>
<li>Say it on a phone call, or send it in a different app.</li>
<li>Or send it as a one-time link that opens once. The steps are in <a href="/blog/how-to-send-a-password-securely/">how to send a password securely</a>.</li>
<li>Make it long and random. A name plus birth year is guessable.</li>
</ul>
<h2 id="can-i-use-a-drive-or-onedrive-link-instead">Can I use a Drive or OneDrive link instead?</h2>
<p>Yes, if you set it up carefully.</p>
<p><strong>Google Drive.</strong> In Share, set General access to <strong>Restricted</strong> so only added people can open it. &quot;Anyone with the link&quot; lets anyone with the URL in, as <a href="https://support.google.com/drive/answer/2494822" rel="noopener" target="_blank">Drive&#39;s help</a> explains. Expiry on access is for eligible work or school accounts only. Under the settings gear you can stop viewers and commenters from downloading, printing and copying.</p>
<p><strong>OneDrive.</strong> Per <a href="https://support.microsoft.com/en-us/office/share-onedrive-files-and-folders-9fcc2f7d-de0c-4cec-93b0-a82024800c07" rel="noopener" target="_blank">Microsoft</a> as of 16 October 2026, an expiry date and a link password need a Microsoft 365 subscription. Block download works only on work or school accounts, and only when editing is off.</p>
<p>Free personal accounts can still use Restricted links. Remove people when the job is done.</p>
<h2 id="how-do-i-send-a-masked-aadhaar-pdf-for-kyc">How do I send a masked Aadhaar PDF for KYC?</h2>
<p>If a PDF holds an Aadhaar, send the masked version. UIDAI&#39;s <a href="https://myaadhaar.uidai.gov.in/" rel="noopener" target="_blank">myAadhaar site</a> lists <strong>Download Masked Aadhaar</strong> under Keep Aadhaar Secure: a digitally signed, password-protected copy that replaces the first 8 digits with &quot;xxxx-xxxx&quot;, needing a mobile OTP.</p>
<p>A 29 May 2022 <a href="https://www.pib.gov.in/PressReleasePage.aspx?PRID=1829162" rel="noopener" target="_blank">PIB clarification</a> withdrew an earlier UIDAI Bengaluru release that had advised masked Aadhaar copies, and said only that holders should use normal prudence when sharing Aadhaar. So masking is a sensible habit, not an official rule. Ask the receiver what they accept. Our guides on <a href="/blog/how-to-share-aadhaar-copy-safely/">sharing an Aadhaar copy safely</a> and <a href="/blog/how-to-watermark-a-pdf-before-sharing/">watermarking a PDF</a> cover the details.</p>
<h2 id="where-does-no-sus-fit">Where does NO SUS fit?</h2>
<p>If you want a link instead of an attachment, a <a href="/one-time-file-link/">one-time file link</a> sends up to 10 files, 50 MB combined. Files are encrypted in your browser with AES-256, and the link keeps the key after the <code>#</code>, which browsers don&#39;t send to our server. It stops working after the first open, or after 1 hour, 24 hours or 7 days if unopened. Use a code instead gives a 6-digit code with no link, for one file or several; a copy of the key then sits on our server until up to 10 minutes after the code is used or expires. You need no account on either side: see <a href="/send-file-without-login/">send a file without login</a>.</p>
<p>To trace a leak, a <a href="/watermark-pdf-viewer-email/">watermarked PDF link</a> asks each viewer for an email and shows it across the page. You get a view log and can revoke the link. Links expire after 30 days by default. The email is typed, not verified, so it is an attribution clue, not proof of identity. Watermarked links are not end-to-end encrypted.</p>
<p>Whoever opens any of these can still screenshot or photograph the PDF. Send it only to someone you would trust with a printout.</p>
