The short answer

Pick the method by what you are protecting. A password-protected PDF keeps the file unreadable to anyone without the password, so send the password through a different channel. Gmail confidential mode limits forwarding, copying, printing and downloads, and Outlook's Do Not Forward blocks copying and forwarding, but a camera can still photograph the screen, and Outlook lets a PDF be downloaded without encryption. For KYC, send a masked Aadhaar from the UIDAI myAadhaar site, watermarked with purpose and date, through a link that expires.

To send a PDF securely, protect the file itself and control the link it travels on. Put an open password on the PDF and send that password by a different channel, or share it through a link that expires and can be limited to named people. Gmail confidential mode and Outlook's Do Not Forward help, but both have gaps, covered below.

None of these stops a recipient from photographing the screen. They reduce who can open the file and how long it lingers. Pick based on what is inside the PDF.

Is Gmail confidential mode secure?

It is a useful lock on the door, not a vault. Per Google's help page, confidential mode lets you set an expiry, remove a recipient's access from your Sent folder, and turn off forwarding, copying, printing and downloading. You can also require an SMS passcode, which works for phone numbers in regions including India.

The limits are written on the same page: recipients can still take screenshots or photos. Google does not describe confidential mode as end-to-end encryption. If the recipient is not on Gmail, they get a link instead of the message, so the content sits on Google's side until they open it.

One number worth knowing: as of 16 October 2026, a personal Gmail account sends and receives up to 25 MB. Bigger attachments become a Drive link automatically, and Drive's own sharing settings then apply.

How do I send a PDF securely in Outlook?

In a new message, open Options, choose Encrypt, then pick Encrypt or Do Not Forward. Microsoft's Outlook encryption page explains the catch for a PDF: under Do Not Forward, PDFs and images can be downloaded without encryption. Word, Excel and PowerPoint files stay encrypted. So for a PDF, Outlook's setting protects the email more than the file.

Recipients on other providers sign in with a Microsoft, Google or Yahoo account or use a temporary passcode. Add a password on the PDF itself if the content matters.

How do I password-protect a PDF for free?

Three free routes, all on your device:

  • Word: Save As PDF, open Options, and choose the encrypt-with-a-password option, per Microsoft.
  • Mac Preview: File, Export, Permissions, then require a password to open it (Apple).
  • Adobe Acrobat: Protect Using Password. Adobe says the "Acrobat X and later" setting uses 256-bit AES and that readers need a version at least that recent (Adobe). It also separates an open password from a permissions password, which only restricts printing, editing and copying.

Use the open password. A permissions password alone lets anyone read the file.

How do I send the password separately?

The password has to take a different road from the file. If both sit in one email thread, anyone who reads that thread has both.

  • Say it on a phone call, or send it in a different app.
  • Or send it as a one-time link that opens once. The steps are in how to send a password securely.
  • Make it long and random. A name plus birth year is guessable.

Can I use a Drive or OneDrive link instead?

Yes, if you set it up carefully.

Google Drive. In Share, set General access to Restricted so only added people can open it. "Anyone with the link" lets anyone with the URL in, as Drive's help explains. Expiry on access is for eligible work or school accounts only. Under the settings gear you can stop viewers and commenters from downloading, printing and copying.

OneDrive. Per Microsoft as of 16 October 2026, an expiry date and a link password need a Microsoft 365 subscription. Block download works only on work or school accounts, and only when editing is off.

Free personal accounts can still use Restricted links. Remove people when the job is done.

How do I send a masked Aadhaar PDF for KYC?

If a PDF holds an Aadhaar, send the masked version. UIDAI's myAadhaar site lists Download Masked Aadhaar under Keep Aadhaar Secure: a digitally signed, password-protected copy that replaces the first 8 digits with "xxxx-xxxx", needing a mobile OTP.

A 29 May 2022 PIB clarification withdrew an earlier UIDAI Bengaluru release that had advised masked Aadhaar copies, and said only that holders should use normal prudence when sharing Aadhaar. So masking is a sensible habit, not an official rule. Ask the receiver what they accept. Our guides on sharing an Aadhaar copy safely and watermarking a PDF cover the details.

Where does NO SUS fit?

If you want a link instead of an attachment, a one-time file link sends up to 10 files, 50 MB combined. Files are encrypted in your browser with AES-256 and the link stops working after the first open, or after 1 hour, 24 hours or 7 days if unopened. A single file's link comes with a 2-digit code that works only together with it, and Use a code instead gives a 6-digit code with no link, for one file or several. The key is also held on our server while either code is valid, 20 or 10 minutes by default. You need no account on either side: see send a file without login.

To trace a leak, a watermarked PDF link asks each viewer for an email and shows it across the page. You get a view log and can revoke the link. Links expire after 30 days by default. The email is typed, not verified, so it is an attribution clue, not proof of identity. Watermarked links are not end-to-end encrypted.

Whoever opens any of these can still screenshot or photograph the PDF. Send it only to someone you would trust with a printout.

Questions people ask

How do I send a PDF securely via Gmail?

Either password-protect the PDF first and send the password by another channel, or use confidential mode to set an expiry and block forwarding, copying, printing and downloading. Confidential mode does not stop screenshots.

Is Gmail confidential mode actually secure?

It is an access control, and Google does not describe it as end-to-end encryption. Google's help page lists expiry, revoke, an optional SMS passcode and blocks on forwarding, copying, printing and downloading, and itself warns that recipients can still take screenshots or photos. Recipients on other email services get a link instead of the message.

How do I send a password-protected PDF and the password safely?

Set an open password, then send the file by email and the password by a different channel, such as a phone call or a one-time link. Never put both in the same email thread. Use a long, random password, not a name or date of birth.

How can I send a PDF securely for free?

Password-protect it in Word, Mac Preview or Acrobat, or share it from Google Drive with General access set to Restricted. For no account on either side, a one-time link such as NO SUS Burn Files works for up to 10 files, 50 MB combined.

Is it safe to send my Aadhaar as a PDF on email or WhatsApp?

Safer if you send the masked copy from UIDAI's myAadhaar site, which hides the first 8 digits, and add a note of who it is for and why. Ask what they accept. Any copy you send can be forwarded or screenshotted.

How do I send a PDF securely online without email?

Use a link instead of an attachment. A Drive or OneDrive link set to specific people, or a one-time link that opens once and then stops working, keeps the file out of inboxes and chat backups. The recipient can still save or photograph what they open.
