The short answer

Privnote, Yopass and PrivateBin encrypt your note in the browser and need no account, while Onetime Secret encrypts on its own server but is open source and ad-free. Bitwarden Send gives the most control over expiry and views and handles files up to 500 MB, but the sender needs an account, and Premium for files. For a single password, any browser-encrypting tool works; pick Yopass or PrivateBin if you want code you can audit or host yourself.

Looking for a Privnote alternative? Privnote and the five tools below all do the same basic job. You paste something sensitive, get a link, and the content is deleted once it's opened or once a timer runs out. The differences that matter are where the encryption happens, whether files are allowed, how long an unopened link survives, and whether anyone can inspect the code. Every detail below was checked on each tool's own site, docs or code as of October 2026.

Browser encryption vs server encryption: why it matters

Five of the six tools encrypt the note on your device before uploading it, then put the decryption key in the part of the link after the #. Bitwarden's Send documentation explains why: browsers don't send that fragment to the server, so the server stores something it cannot read. Yopass and PrivateBin work the same way.

Two things follow from this:

  1. The full link is the secret. Anyone who gets the complete link before your recipient can read the note. Treat the link like the password itself.
  2. You are trusting the code the site serves. Open-source code can be audited, and you can run your own copy. Privnote describes browser-side encryption in its privacy policy, but its site links to no source code, so you are taking its word for it.

Onetime Secret takes a different approach. Its docs say secrets are encrypted on its servers. If you add a passphrase, its about page says it stores only a bcrypt hash, so the operator can't decrypt the saved secret afterwards. The plain text still reaches its server when you click create, though. That is fine for many uses, but it asks for more trust than a tool that never sees your plain text.

Privnote: the simplest, but watch for ads and fakes

Privnote needs no registration or password. By default, the note page asks the recipient to confirm before it shows and destroys the note. Under "Show options" you can switch to a timed note, set your own password, add a reference name, and get an email when the note is read. Unread notes are deleted after 30 days.

There are two downsides. The homepage carries third-party ads, and the privacy policy says third parties place cookies for commercial and promotional purposes. And Privnote has been cloned: in April 2024, KrebsOnSecurity reported on lookalike sites that worked normally but swapped any cryptocurrency wallet address in a note for the scammers' own. Type the address yourself or use a bookmark instead of clicking a search result.

Onetime Secret: open source, text only, pick your data region

Onetime Secret is open source under the MIT license and documents self-hosting. Without an account, secrets last up to 7 days and can be up to 100 KB. A free account raises that to 14 days and 1,000 KB (about page). It deliberately doesn't accept files, because files can carry metadata that reveals who sent or received them. Its homepage says each secret stays in the region you pick, with servers in Canada, Germany, New Zealand, the UK and the US.

Its privacy statement says it hosts no ads and uses no third-party analytics. As of October 2026, the free account already includes one custom domain, and the paid plans (€35 and €125 a month) add unlimited domains, logo branding and 30-day expiry.

Bitwarden Send: best if you already use Bitwarden

Send is built into Bitwarden. A text Send holds up to 1,000 encrypted characters (Bitwarden says about 700 typed characters reach that limit), and a file Send up to 500 MB, or 100 MB on mobile (About Send). Every Bitwarden user can create text Sends. File Sends need Premium or a paid organization plan, plus a verified email (Create a Send). As of October 2026, Premium is listed at $19.80 a year, and the same page says Sends can go to anyone, including people without Bitwarden.

It has the most lifespan controls of any tool here (Send Lifespan): a deletion date (7 days by default, up to roughly a month), a separate expiry date and a view limit. You can also add a password, hide your email address, and on paid plans require recipients to verify their email (Send Privacy). Bitwarden's apps are open source, mostly under GPL v3. The catch is that the sender needs a Bitwarden account.

Yopass: open source and easy to self-host

Yopass (Apache 2.0) encrypts in the browser with OpenPGP, needs no accounts, and says it collects no tracking data. The public demo offers 1 hour, 1 day or 1 week, and caps file uploads at 512 KB. The project's own README says the demo is for testing and that you should self-host for sensitive information. Free self-hosted installs cap files at 1 MB. A €149-a-year business license allows larger uploads and adds read receipts and secret requests.

Yopass 15.0.0, released on 9 October 2026, changed how links without a key behave. They now wait for the recipient to enter the key before fetching the secret, which helps stop email security scanners that click links from burning a one-time message first.

PrivateBin: a pastebin with burn after reading

PrivateBin is an open-source pastebin under the zlib/libpng license that encrypts with AES-256-GCM in the browser. It adds things the others don't, like Markdown and source-code formatting and optional discussion threads. File uploads are off by default, and the sample config sets a size limit of about 10 MB. Each instance chooses its own settings. The privatebin.net instance runs version 2.0.6, allows attachments, and offers expiry from 5 minutes to 3 days with a burn-after-reading checkbox. Since anyone can run an instance, use one run by someone you trust, or host your own.

Where NO SUS fits

NO SUS Burn Notes and Burn Files work on the website with no account for the sender or recipient. Encryption happens in your browser (AES), and the direct link keeps the key after the #. A link opens once. Unread notes expire after 7 days, and for files you pick 1 hour, 24 hours or 7 days. Burn Files carries up to 10 files, 50 MB combined, in one link, which suits a few scanned documents. Two limits: NO SUS is not open source, and every single note or file made on the website also gets a two-digit code that works only with its link, so its key is held on the server while that code is valid (20 minutes by default), whichever link you share. The six-digit code you can ask for instead needs no link, opens once and lasts up to 10 minutes, and the server holds the key for it too. Which one should you use?

  • A single password or Wi-Fi key: Privnote, Yopass or PrivateBin, with no signup. Our guide on how to send a password securely covers sending the link one way and its password another.
  • You want to audit or self-host: Yopass or PrivateBin. Onetime Secret suits you if server-side encryption is acceptable and you want to choose the data region.
  • You already have Bitwarden: use Send. It has the finest control over views and expiry.
  • Files: Yopass and PrivateBin handle small files with no signup. For larger scans or PDFs, Bitwarden Send takes up to 500 MB if you have Premium, and NO SUS Burn Files takes up to 50 MB with no account on either end. If it's an ID document, read how to share an Aadhaar copy safely first.

Mistakes that defeat a one-time link

  1. Sending the link and its password in the same message. If that chat leaks, both leak together. Send the password through a different app or say it on a call.
  2. Letting a bot open it first. Some email security systems click links to scan them, which is why Yopass changed its link handling in 15.0.0. A tool that makes the recipient click a button or enter a key before revealing, like Privnote's default confirmation step, lowers this risk.
  3. Using a lookalike domain. Check the address bar before you paste anything into a note site.
  4. Assuming the note is truly gone. The recipient can copy, screenshot or photograph it, and Privnote's own FAQ admits it can't stop that. The same is true of disappearing messages in chat apps.

Questions people ask

Is Privnote safe to use?

Privnote says notes are encrypted in your browser and the key exists only in the link, so its servers can't read them. Its code isn't public, it shows third-party ads, and lookalike Privnote sites have been used to steal cryptocurrency, so type privnote.com yourself instead of clicking a search result.

Which self-destructing note tools are open source?

Onetime Secret (MIT), Yopass (Apache 2.0), PrivateBin (zlib/libpng) and Bitwarden (mostly GPL v3) publish their code. Yopass, PrivateBin and Onetime Secret document how to self-host. Privnote and NO SUS are not open source.

Can the recipient keep a copy of a self-destructing note?

Yes. Once the note is on their screen they can copy, screenshot or photograph it. These tools only stop the link from working a second time and delete the stored copy.

Which self-destructing link tools can send files?

Bitwarden Send handles files up to 500 MB, but only for senders on Premium or a paid organization. Yopass and PrivateBin allow small files depending on the instance, and NO SUS Burn Files sends up to 10 files, 50 MB combined, with no account. Privnote and Onetime Secret are text only.

Does Onetime Secret encrypt in the browser?

No. Its documentation says secrets are encrypted on its servers. With a passphrase it keeps only a bcrypt hash of the passphrase, but the plain text still reaches its server when you create the secret.
