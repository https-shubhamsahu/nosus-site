32:T3e07,<p>An Aadhaar copy for a SIM card, mark sheets for an admission, a resume for a recruiter, salary slips for a flat. Once a copy leaves your phone, you lose control of where it goes. A watermark makes every copy carry a visible note of what it was meant for, so misuse is easier to spot and harder to explain away. Menu paths below are as of October 2026.</p>
<h2 id="what-should-a-watermark-on-an-id-copy-say">What should a watermark on an ID copy say?</h2>
<p>Make the text specific enough that the copy looks wrong anywhere else. Answer three things:</p>
<ul>
<li><strong>Why:</strong> &quot;For SIM KYC only&quot;, &quot;For rental verification only&quot;.</li>
<li><strong>For whom:</strong> the company, branch or person, e.g. &quot;XYZ Bank, Andheri branch&quot;.</li>
<li><strong>When:</strong> the date you are sharing it. A dated copy is hard to reuse months later without someone noticing.</li>
</ul>
<p>A full example: <code>For KYC at XYZ Bank only | 12 Oct 2026 | Not valid elsewhere</code>.</p>
<p>Placement matters as much as wording. Run it diagonally and semi-transparent across the page so it crosses the photo and part of the text. Keep the name and number readable, because the person receiving it still has to verify them. A label parked in an empty corner can be cropped off in one tap.</p>

<h2 id="which-tool-should-you-use-to-watermark-a-pdf">Which tool should you use to watermark a PDF?</h2>
<p>If the document is sensitive, use something that runs on your own device. Online tools are fine for a resume or notes, not for ID copies.</p>

<h2 id="how-do-you-add-a-watermark-in-microsoft-word">How do you add a watermark in Microsoft Word?</h2>
<p>These steps follow <a href="https://support.microsoft.com/article/f90f26a5-2101-4a75-bbfe-f27ef05002de" rel="noopener" target="_blank">Microsoft&#39;s watermark help page</a>:</p>
<ol>
<li>Open the document in the <strong>Word desktop app</strong>. Word for the web can show a watermark but can&#39;t add or change one.</li>
<li>Go to <strong>Design &gt; Watermark &gt; Custom Watermark</strong> and choose a text watermark. On a Mac, Design &gt; Watermark opens the same dialog; select <strong>Text</strong>.</li>
<li>Type your text or pick a preset such as DRAFT, then set the font, size, colour and layout. Diagonal is harder to crop out than horizontal.</li>
<li>Click <strong>OK</strong>. If you can&#39;t see it, switch to <strong>View &gt; Print Layout</strong>.</li>
<li>Save it as a PDF: <strong>File &gt; Save a Copy</strong> (or Save As), then choose <strong>PDF</strong> in the format list, per <a href="https://support.microsoft.com/en-us/office/save-or-convert-to-pdf-or-xps-in-office-desktop-apps-d85416c5-7d77-4fd6-a216-6f4bf7c7c110" rel="noopener" target="_blank">Microsoft&#39;s PDF export guide</a>.</li>
</ol>
<p>Send the PDF, not the .docx. In a Word file the watermark is something any Word user can change. If you paste an ID photo onto the page, open the exported PDF and check that the watermark actually shows over the photo; if the picture hides it, use the Preview or phone method below, which writes the text on top of the image.</p>
<h2 id="how-do-you-watermark-a-pdf-for-free-with-libreoffice">How do you watermark a PDF for free with LibreOffice?</h2>
<p><a href="https://www.libreoffice.org/discover/libreoffice/" rel="noopener" target="_blank">LibreOffice</a> is a free, open-source office suite, and everything happens on your computer. Its current help pages describe two ways.</p>
<p><strong>Writer&#39;s watermark (more control).</strong> From the <a href="https://help.libreoffice.org/latest/en-US/text/swriter/01/watermark.html" rel="noopener" target="_blank">Page Watermark help page</a>:</p>
<ol>
<li>Open the document in LibreOffice Writer.</li>
<li>Go to <strong>Format &gt; Watermark</strong>. In the tabbed interface it is under the <strong>Layout</strong> tab.</li>
<li>Type your text, then choose the font, angle, transparency and colour. You can&#39;t set the font size; Writer scales the text to fit one line across the page.</li>
<li>Export the document as a PDF from the File menu.</li>
</ol>
<p>The watermark applies to the current page style, so every page using that style gets it.</p>
<p><strong>Watermark during PDF export (quickest).</strong> In the PDF export dialog&#39;s General tab, tick <strong>Sign with watermark</strong> and type your text. According to <a href="https://help.libreoffice.org/latest/en-US/text/shared/01/ref_pdf_export_general.html" rel="noopener" target="_blank">LibreOffice&#39;s export help</a>, this adds a centred, vertical, light green watermark whose position, orientation and size you can&#39;t change, and it isn&#39;t saved in your original file.</p>
<p>Both help pages say the watermark goes on the page background. An opaque photo pasted onto the page will cover it where they overlap, so for ID photos use the Preview or phone method below.</p>
<h2 id="can-you-watermark-a-pdf-in-adobe-acrobat-for-free">Can you watermark a PDF in Adobe Acrobat for free?</h2>
<p>Not with the free tools, going by Adobe&#39;s own pages as of October 2026. The <a href="https://www.adobe.com/acrobat/online.html" rel="noopener" target="_blank">Acrobat online tools page</a> lists converting, merging, splitting, compressing, signing and protecting, but no watermark tool. The <a href="https://www.adobe.com/acrobat/pdf-reader.html" rel="noopener" target="_blank">Acrobat Reader page</a> says text and image editing needs a paid Acrobat plan.</p>
<p>If you already have Acrobat through college or work, Adobe&#39;s <a href="https://www.adobe.com/in/acrobat/roc/blog/add-a-watermark-to-a-pdf.html" rel="noopener" target="_blank">watermark walkthrough</a> goes like this: open the PDF, then in the edit tools under <strong>Add content</strong>, choose <strong>More &gt; Watermark &gt; Add</strong>. Pick text or an image, and set the font, size, opacity, rotation, page range and whether it shows on screen, in print or both. An <strong>Apply to multiple files</strong> option stamps several PDFs at once.</p>
<p>The same walkthrough covers removing a watermark, and Adobe&#39;s <a href="https://www.adobe.com/in/acrobat/roc/blog/step-by-step-guide-to-online-pdf-watermarking.html" rel="noopener" target="_blank">online guide</a> covers editing one. That&#39;s the catch with every PDF watermark: it is a separate element, not permanent ink.</p>
<h2 id="does-preview-on-mac-have-a-watermark-option">Does Preview on Mac have a watermark option?</h2>
<p>Not a dedicated one. The closest is the Markup <strong>Text</strong> tool, described in <a href="https://support.apple.com/guide/preview/annotate-a-pdf-prvw11580/mac" rel="noopener" target="_blank">Apple&#39;s Preview guide</a>:</p>
<ol>
<li>Open the PDF in Preview and click <strong>Show Markup Toolbar</strong>.</li>
<li>Choose the <strong>Text</strong> tool, type your label and drag it into place. Change the font and colour with the Text Style button.</li>
<li>To lock it in, choose <strong>File &gt; Print</strong>, then <strong>Save as PDF</strong>. Apple says this flattens annotations &quot;so that they can&#39;t be edited.&quot; Plain File &gt; Save or Export keeps them editable.</li>
</ol>
<p>It works one text box at a time, so it suits short documents.</p>
<h2 id="how-do-you-watermark-an-id-photo-on-your-phone">How do you watermark an ID photo on your phone?</h2>
<p><strong>Android, with Google Photos</strong> (<a href="https://support.google.com/photos/answer/6128850?hl=en&co=GENIE.Platform%3DAndroid" rel="noopener" target="_blank">Google&#39;s help page</a>):</p>
<ol>
<li>Open the photo and tap <strong>Edit &gt; Markup</strong>. On some phones it&#39;s <strong>Edit &gt; Tools &gt; Markup</strong>.</li>
<li>Tap <strong>Text</strong>, type your label, then press and hold to drag it into place.</li>
<li>Tap the checkmark, then <strong>Save as copy</strong> so your original stays untouched.</li>
</ol>
<p><strong>iPhone, with Photos</strong> (<a href="https://support.apple.com/en-us/119875" rel="noopener" target="_blank">Apple&#39;s Markup page</a>):</p>
<ol>
<li>Open the photo, tap <strong>Edit</strong>, then the <strong>Markup</strong> button.</li>
<li>Tap the <strong>Add</strong> (+) button, choose text, type your label and drag it into place.</li>
<li>Tap <strong>Done</strong>, then <strong>Done</strong> again.</li>
</ol>
<p>One short line is easy to crop. Write the label two or three times across the image, including once over the photo. If Google Photos backup is on, your photos, including the edited copy, are saved to your Google Account, per <a href="https://support.google.com/photos/answer/6193313?hl=en&co=GENIE.Platform%3DAndroid" rel="noopener" target="_blank">Google&#39;s backup help</a>. Check that setting before you photograph IDs.</p>
<h2 id="is-it-safe-to-watermark-documents-on-ilovepdf-smallpdf-or-pdf24">Is it safe to watermark documents on iLovePDF, Smallpdf or PDF24?</h2>
<p>They work, but your file is uploaded to their servers. Their stated policies, as of October 2026:</p>
<ul>
<li><strong><a href="https://tools.pdf24.org/en/add-watermark" rel="noopener" target="_blank">PDF24</a>:</strong> free and ad-funded, no sign-up. Files are deleted from its server after one hour. You can set angle and transparency, or fill the whole page with the text.</li>
<li><strong><a href="https://www.ilovepdf.com/pdf_add_watermark" rel="noopener" target="_blank">iLovePDF</a>:</strong> text or image watermarks with opacity, rotation and page range. Its <a href="https://www.ilovepdf.com/pricing" rel="noopener" target="_blank">pricing page</a> limits free-plan batch watermarking to 2 files at a time and keeps the desktop app, which its <a href="https://www.ilovepdf.com/blog/pdf-compliance-gdpr-ilovepdf" rel="noopener" target="_blank">GDPR page</a> says processes files on your device, for paid plans. Files from the standard web tools are deleted within two hours.</li>
<li><strong><a href="https://smallpdf.com/watermark-pdf" rel="noopener" target="_blank">Smallpdf</a>:</strong> free text watermarks with unspecified usage limits for free users. It says files are deleted one hour after processing.</li>
</ul>
<p>These are the companies&#39; own statements, not independent audits. For a resume or class notes, that&#39;s a fair trade. For Aadhaar, PAN, passport or bank statements, stay offline. Same thinking as not leaving copies behind at the <a href="/blog/print-shop-document-privacy/">Xerox shop</a>.</p>
<h2 id="visible-vs-invisible-watermarks-whats-the-difference">Visible vs invisible watermarks: what&#39;s the difference?</h2>
<p>A <strong>visible</strong> watermark is text or a logo anyone can see. Its job is context and deterrence.</p>
<p>An <strong>invisible</strong> watermark is a signal hidden inside the file that needs software to detect. Google DeepMind&#39;s <a href="https://deepmind.google/models/synthid/" rel="noopener" target="_blank">SynthID</a>, for example, marks AI-generated content and, for images and video, is designed to survive cropping, filters and compression. The everyday tools above only add visible watermarks.</p>
<p>The practical version for everyone else is a <strong>unique copy per recipient</strong>. Put each recipient&#39;s name in their copy&#39;s watermark. If one leaks, the label tells you which copy it was. Variation also helps: a 2017 <a href="https://research.google/pubs/on-the-effectiveness-of-visible-watermarks/" rel="noopener" target="_blank">Google Research paper</a> showed that a watermark applied the same way across many images can be estimated and removed automatically, and looked at inconsistencies in the watermark as a defence.</p>
<h2 id="what-can-a-watermark-not-stop">What can a watermark not stop?</h2>
<ul>
<li><strong>Cropping.</strong> A watermark in the margin disappears with one crop. Put it across the content.</li>
<li><strong>Retyping.</strong> Someone can copy your name, number and address by hand. A watermark protects the picture, not the information, so share as little as you can.</li>
<li><strong>Editing it out.</strong> PDF watermarks can be edited or removed with an editor. Image watermarks can be painted out with AI: in March 2025, <a href="https://techcrunch.com/2025/03/16/people-are-using-googles-new-ai-model-to-remove-watermarks-from-images" rel="noopener" target="_blank">TechCrunch reported</a> people using an experimental Gemini 2.0 Flash feature to strip watermarks from stock photos, though it struggled with some semi-transparent marks and ones covering large areas. That was one model, over a year ago, so treat no watermark as removal-proof.</li>
<li><strong>Screenshots, photos of the screen and prints.</strong> Nothing inside a file prevents these.</li>
<li><strong>Proving who leaked it.</strong> A label tells you which copy leaked, not who leaked it.</li>
<li><strong>Controlling who opens it.</strong> A watermark is not a password or encryption. Anyone with the file can read it.</li>
</ul>
<h2 id="where-no-sus-fits">Where NO SUS fits</h2>
<p>If you&#39;d rather not decide each recipient&#39;s label in advance, a watermarked link in the NO SUS app watermarks the document with the email the viewer enters, and gives you an access history, expiry or view limits, and a revoke option. Revoking stops new access through the link; downloaded files, screenshots and prints can&#39;t be recalled. Watermarked links are not end-to-end encrypted, and a viewer-entered email is an attribution clue, not proof of identity. Details are in the <a href="/guides/#watermark">watermarked links guide</a>. If you&#39;re on the receiving end, see <a href="/blog/how-to-collect-documents-from-clients-securely/">collecting documents from clients securely</a>.</p>
