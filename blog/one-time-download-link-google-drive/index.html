Drive can limit who opens a file, end a person's access on a date (on work and school accounts) and hide the download button. If the file should be gone after one download, put it in a one-time link and send that instead.

Can Google Drive make a one-time link?

Not built in. A Drive link keeps working for as long as its sharing settings allow. With General access set to Anyone with the link, Google says anyone who has the link can open the file without signing in to a Google account. Nothing in the help pages counts opens or downloads.

The workarounds people try are all manual:

  • Switch it back to Restricted after they download it. Only people you added can open it then. You have to notice the download first, and it can't reach the copy they saved.
  • Delete the file afterwards. Google notes that if you delete a shared file you own, people it was shared with can still make a copy until you delete it permanently.
  • "Direct download" links passed around on forums. We found no Google help page that documents them, so don't count on how they behave.

How to make a Google Drive link expire

On eligible work or school accounts, a person's access can end on a date (Google Drive Help):

  1. Open Share and add the person.
  2. Click the arrow next to their name and choose Add expiration.
  3. Pick a date within one year.

The limits: personal Google accounts don't have it, folders allow it only for viewers, and Google describes it per person. Its pages describe no expiry for an Anyone with the link link. When access to a file expires, Google says the person falls back to whatever access they have on the folder it sits in.

How to stop people downloading a Drive file

In Share, open Settings and untick viewers and commenters under the option for who can download, copy and print (Google Drive Help). Google adds its own caveat: the limits work only inside Drive, Docs, Sheets and Slides, and you can't stop people sharing the content in other ways. A screenshot or a phone camera still works, as it does on any website.

What a one-time link does not do

  • It can't take back the copy they downloaded. One-time means the link, not their copy.
  • It can't stop a screenshot or a photo of the screen.
  • Whoever opens it first uses it up. If your recipient finds it already used, assume someone else got the file and tell them.

Questions people ask

Can I create a one time download link in Google Drive?

No. Drive's sharing help describes no link that works for one open or one download. You can restrict the file to named people and remove access after they download it, or send the file through a one-time link tool instead.

How do I make a Google Drive link expire?

On an eligible work or school account, share the file with the person, click the arrow next to their name and choose Add expiration, then pick a date within one year. Personal Google accounts don't have this, and Google's pages describe it per person, not for an Anyone with the link link.

Can I limit the number of downloads on a Google Drive link?

Not by number. You can stop viewers and commenters downloading, printing and copying in Share, then Settings, but Google says these limits apply only inside Drive, Docs, Sheets and Slides. A tool with a one-open limit can end the link after one open: a NO SUS Burn File does it on the first download, and in Bitwarden Send you set Limit views to 1.

Does turning off link sharing remove the file they already downloaded?

No. Setting the file back to Restricted stops new opens through the link. A copy someone already saved is on their device, and no Drive setting can reach it.

Is a one-time download link safe for sensitive files?

Safer than a link that works forever, because it stops working after the first download and the stored copy is deleted. It can't take back the downloaded copy or stop a screenshot, and whoever opens it first uses it up.
