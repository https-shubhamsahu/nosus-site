Is NO SUS safe and private?

Each tool protects differently. Burn notes and files are encrypted on your device with AES-256 and deleted once opened. The key travels in the link after the #, which browsers never send to our server. Our server holds a copy only if you ask for a 6-digit code, until up to 10 minutes after it is used or expires. Watermarked links are not end-to-end encrypted. NO SUS Chat lives in your own Google Drive, not on our servers.

What we log

  • Burn needs no account. We never know who opened a link. If you send one while signed in to the app, we know which account sent which link, never what is in it or who opened it, so we can tell you when it is opened. That tie is deleted when the link is opened or expires. A guest's link is tied to no one. Burn File, code and Canary requests are rate-limited using a salted hash of your IP address; the Burn File upload counters are swept after 24 hours.
  • Links you sent are listed only in this browser, never the link or its key. Our server keeps a fingerprint of a random receipt code against the note or file and records only that it was opened and when, never who opened it.
  • Watermarked links: the email each viewer types (not verified), the device type and when they opened and closed it. Only you, the sender, can read this log.
  • Groups: uploads, views, membership changes and screenshot attempts go in an audit log that group members can see.
  • Traceable copies: the name each reader types and when they opened it. Solana devnet, a public test network, gets only hashes.
  • Website and app: Cloudflare Web Analytics with no cookies, never loaded on a link that carries a share key. nosus.foo also sends a few PostHog funnel events (page path, a random per-tab ID; note or file, starter used or not, how a link was shared, rough time to open, sent list shown), never note text, file names, links or keys, and never on a link that carries a key. The app sends a fixed list of usage events with no file names or keys, and has no off switch yet.

What we cannot do

  • Block screenshots or photos in a browser. No website can. Only the Android app's PDF viewer blocks screenshots.
  • Verify who someone is. A watermark shows the email a viewer typed and Canary shows the name a reader typed. Nothing checks that either is real.
  • Make watermarked links end-to-end encrypted. We store the file and serve it.
  • Recall a copy. Revoking a link stops new opens, but downloaded, printed or photographed copies are out of reach.
  • Prove a leak. Canary points to whose copy leaked. It is a strong hint, not proof.

How to check us in four steps

The app's source code is private, so there is no code to audit. You can still watch what your browser sends.

  1. 1

    Step 1: Open DevTools

    On nosus.foo, press F12 and open the Network tab.

  2. 2

    Step 2: Make a note

    Type anything into the burn tool and create the note.

  3. 3

    Step 3: Read the upload

    The request to burn_notes carries a ciphertext field, not your text.

  4. 4

Questions

Is NO SUS safe for sending a password or a private file?

It is built for that. A one-time note or file is encrypted on your device and deleted once opened. Anyone who gets the link first can open it once, so share it only with the right person.

Can NO SUS read my burn note?

Your device encrypts it before upload. The link carries the key after the #, which browsers do not send. We get a copy of the key only if you ask for a 6-digit code, on the website or in the app. We keep it until up to 10 minutes after the code is used or expires, so in that window we hold both the encrypted note and its key.

What encryption does NO SUS use? Is it AES-256-GCM?

Not GCM. Notes use AES-256 in CTR mode and files use AES-256 in CBC mode, both through the browser's Web Crypto API with a fresh random key each time.

Where is my NO SUS data stored?

Account data, burn notes, burn files and watermarked-link files are on Supabase, in its Mumbai (India) region, with TLS in transit and row-level security. NO SUS Chat files stay in a NO SUS folder in your own Google Drive, not on our servers.

Can someone screenshot a NO SUS note or document?

In a browser, yes, because no website can block screenshots. On a watermarked link the page carries the viewer's email and the open is logged, so a leak can be traced. The Android app's PDF viewer blocks screenshots.

Is NO SUS open source?

No. The source repository is private, and only built APKs and the compiled website are published. You can still check what the browser sends, using the steps above.
